## 〇、整体：识别题目 + 解题思路（拿到题先走这一层）

> 用途：考场/刷题先看这层——先"识别题型"再"走模块思路"，不要一上来就硬算。识别依据来自提问方式与题干特征（详细路由见 考点速览·极速路由）。

### 1. 整体识别题目（看问法/特征 → 定题型）

- 🟢 总原则：先定题型，再找方法；混淆题型 = 用错方法、白费时间
- 言语理解（看提问方式）
	- 主要介绍/意在说明/概括最准确 → **主旨观点题**
	- 最适合做标题 → **标题添加题**
	- 理解（不）准确/与原文相符/没有提及 → **细节题**
	- 接下来最可能讲述 → **下文推断题**；文中"X"指的是 → **词语理解题**
	- 依次填入横线（实词/成语/关联词） → **逻辑填空**
	- 句子排序/填句子 → **语句表达**；一篇文章带 5 小题 → **文章阅读**
- 判断推理（看题型标识）
	- 所有/有些/某个、真假话、如果…那么 → **命题推理**（直言/联言选言/假言/朴素逻辑）
	- 找突破口/元素匹配 → **朴素逻辑**
	- 最能削弱/加强/补充前提 → **论证题**
	- 图形找规律/折纸盒/拼接 → **图形推理**
	- 符合/不符合该定义 → **定义判断**
	- 两词/三词/括号找关系 → **类比推理**；5 短句排序 → **事件排序**
- 数量关系（看题干形态）
	- 文字+数字的数学运算应用题 → 识别题型（经济/工程/行程/排列组合…）→ 选方法
	- 纯数列（一组数字） → **数字推理**
- 资料分析（看题干关键词）
	- "占/占比/比重" → **比重**；"平均每/人均/单位" → **平均数**
	- 现期/基期/增长量/增长率 → **增长类**（一般/间隔/年均/混合）
	- "是…几倍" → **倍数**；纯加减乘除估算 → **速算与比较**

### 2. 整体解题思路（模块主线，先想清路径再下笔）

- 🟢 通用四步：① 识别题型 → ② 调用对应规则/公式 → ③ 估算或推导 → ④ 复核易错陷阱
- 言语理解主线：宏观找主旨 · 微观防五坑 · 填空定关系 · 语句抓标志
- 判断推理主线：形式逻辑背规则 · 论证拆三要素 · 图形按特征找规律 · 定义抓要点 · 类比找关系
- 数量关系主线：先识别题型 → 再选方法（方程/比例/赋值/十字交叉） → 最后套公式并检查边界条件
- 资料分析主线：列式（四量互推） → 速算（选项必有差距，估算即可） → 先微观定位、综合分析放最后

## 一、言语理解（模块主线：宏观找主旨 · 微观防五坑 · 填空定关系 · 语句抓标志）

### 片段阅读（提问方式定题型，主旨观点题是根基）

- **主旨观点题**（主要介绍/意在说明/概括最准确）★★★★★
	- 🟢 三步法：主题词 → 层次 → 选项
	- 主题词：高频词、关键句陈述对象 → 先排"偏题"项
	- 层次：转折——重点多在转折后；承接、解释；并列——无主次需提炼共性或全面概括
	- 隐性主旨三类：重要性+缺陷、问题+危害、问题+原因 → 选针对且可操作的**对策**
	- 选项：先同义转述，再排除——侧重不同/偷换概念/概括不全/推断过度
- **标题添加题**（最适合做标题）★★★
	- 能力等同主旨观点题 + 标题三特点：主旨明确、内容精炼、形式新颖
- **细节题**（理解(不)准确/与原文相符/没有提及）★★★★
	- 🟢 回文定位，查设错五坑
	- 🔴 五坑：无中生有、正话反说、绝对表述、偷换概念、混淆范围
	- 细节查找：定查找内容 → 定位原文 → 筛选项
- **下文推断题**（接下来最可能讲述）★★★
	- 🟢 只看尾句：尾句提话题→延续话题；尾句提问题→分析/解决
	- 三排除：无关信息、本文信息（已论述）、跳跃信息
- **词语理解题**（文中"X"指的是）★★★
	- 指代性词语：前文就近找；特殊含义词语：贴近主题+注意修辞

### 逻辑填空（双维度：语境定方向 → 词语定选项）

- **语境分析** ★★★★★
	- 🟢 三步：定关系 → 找提示信息 → 筛选项
	- 🔴 四大关系·判定标志：
		- 反对：转折词（虽然…但是/然而/不过/却/实际上）、对照词（多…/过去…如今/并非…而是/不同于）、否定词（无法/不可能/没有/不会）
		- 解释：同义互换（无异于/换言之/或者说/如/像）、指代词、冒号/破折号、总结词、因果/假设/条件词；无标志看空前空后
		- 递进：甚至/而且/竟/更/上升到/以至/不仅…而且/何况——方向一致程度有别
		- 并列：和/又/另外/此外/既…又、或者/要么、顿号/分号、并列短语句
- **词语辨析** ★★★★★
	- 两法：语素联想法（拆语素释义/组词）、语境联想法（日常/官媒用法）
	- 🔴 五角度：词义侧重、词义轻重、搭配对象、感情色彩、句法功能
- **虚词辨析** ★★：关联词搭配 + 句间关系

### 语句表达（排序抓首句+标志，填空看位置，病句走主干→关键词）

- **句子排序** ★★★★
	- 🟢 三步：定首句 → 抓五类标志 → 句间关系定顺序
	- 🔴 不做首句：指代不明、转折/因果/总结词开头、具体描述句
	- 可做首句：背景介绍、概念介绍、引用
	- 五类标志：指代词（在所指对象后）、关联词（定逻辑顺序）、顺序词（时间从古至今/空间渐进）、总结词（置尾句）、重复词（捆绑：引出→解释→应用）
- **句子填空** ★★★★
	- 两原则：话题一致 + 句间关系一致
	- 位置定作用：段首引话题/总领、段中承上启下、段尾总结/结论
- **病句辨析** ★★★
	- 🔴 八大类型：用词不当、搭配不当、语序不当、成分残缺、成分赘余、表意不明、结构混乱、不合逻辑
	- 🟢 检查两步：主干枝叶梳理 + 关键词语检查（并列成分、关联词）

### 文章阅读（一篇文章5题，先微观后宏观，边读边标记）★★★★

- 微观类5种：细节判断/细节查找/句子填空/词语理解/逻辑填空 → 遇空填空，遇排则排
- 宏观类3种：主旨观点/标题添加/语段归位
- 作答三步：看题定题型 → 读文做标记（关联词/指代词/总结词；首尾句/观点句/结论句）→ 先微观后宏观

## 二、判断推理（主线：形式逻辑背规则 · 论证拆三要素 · 图形按特征找规律 · 定义抓要点 · 类比找关系）

### 逻辑判断

- **直言命题**（所有/有些/某个、真假话）★★★
	- 🔴 六类型：所有/有些/某个 × 是/非
	- 矛盾三对：所有A是B↔有些A非B、所有A非B↔有些A是B、某个A是B↔某个A非B → 矛盾法"一找二绕三回"
	- 推出（知真求真）：所有A是B→某个A是B→有些A是B
	- 反对：上反对（所有是↔所有非，至少一假）、下反对（有些是↔有些非，至少一真）
	- 三段论：四种标准形式、文氏图；前提型用排除法、结论型用画图法
- **联言、选言命题**（且/或/要么…要么）★★★
	- 联言p且q：一假则假、全真则真；矛盾=非p或非q
	- 相容选言p或q：一真则真、全假则假；矛盾=非p且非q
	- 不相容选言"要么p要么q"：有且只有一种情况为真
- **假言命题**（如果…那么/只要…就/只有…才）★★★★★
	- 🔴 翻译：充分在前=前→后（如果…那么/只要…就）；必要在前=后→前（只有…才）
	- 🔴 推理规则：肯前必肯后、否后必否前；否前/肯后推不出必然结论（逆否等价）
	- 🟠 矛盾=p且非q
	- 真假话用矛盾法"一找二绕三回"
- **朴素逻辑**（找突破口/元素匹配）★★★★★
	- 🟢 突破口思维：确定条件、关联条件（出现次数多的元素）
	- 三方法：代入排除法（选项对应关系给得全）、假设法（真假话不确定）、图表法（列表/画图）
- **论证基础** ★★★★★
	- 三要素：结论、论据、论证联系
	- 找结论标志词：因此/所以/认为/说明/表明/意味着/由此可知/据此推出
	- 剔除背景说明/概念介绍/以往认知，提炼对象及性质/原因/结果/影响/做法
- **削弱型**（最能削弱）★★★★★
	- 🔴 三角度：削弱结论（直接否定；只有结论型仅此路）、削弱论证联系（概念或对象不一致时优先）、削弱论据（观点/调查/实验时）
- **加强型**（最能加强/支持/补充前提/假设）★★★★★
	- 三角度：加强结论、加强论证联系（概念或话题不一致时优先，建立联系）、加强论据
	- 前提型：搭桥法（找论据与结论的不同概念→建立联系）、反向验证法（否定选项代入，结论不成立者为必需前提）
- 🔴 **力度比较**：本质>现象、必然>可能、量大>量小、直接>间接、综合>单一 ★★★★★
- 解释/结论/评价型 ★★：解释找现象→找原因；结论选项代入定位；评价（相似结构）选推理形式一致的选项

### 图形推理（相似看位置叠加 · 相异看特性数量 · 立体折叠 · 拼接定方法）

- **位置规律**（元素完全相同）★★★★★
	- 平移（方向+距离）、旋转（方向+角度：30°/45°/60°/90°）、翻转（左右/上下）
- **叠加规律**（元素同中有异）★★★★★
	- 直接叠加、去同求异、去异求同、特殊运算（黑白运算）
- **图形特性**（相似度低且自身特性明显）★★★★★
	- 对称（轴对称：对称轴数量/方向/与点线面关系；中心对称；轴+中心）
	- 直曲（全直/全曲/有直有曲）、开闭（开放/封闭）
- **数量规律**（无明显特性）★★★★★
	- 数点（交点/十字/直曲/切点/内外部）、数线（直线/曲线/笔画数）、数面（封闭区域/部分数）、数元素（种类/个数）、数角（锐/直/钝）
- 元素分布 ★★★：元素遍历、相对位置
- **立体图形** ★★★
	- 六面体：相对面不相邻（同行/列隔一个面、"Z"字形两端）；相邻面相对位置不变（看公共边）
	- 三视图、截面图、四面体
	- 立体拼接：凹凸一致、"个数"相等、分层讨论
- 平面拼接 ★★★：特殊线条法、平行线条拼接法、最大面定位法

### 定义判断（抓八要点 → 排除法）

- **单定义** ★★★★★
	- 🔴 八要点：主体、客体、目的、方式、原因、结果、条件、属性
	- 排除法 + 跳读无效信息
- **多定义** ★★★：问哪个、看哪个；关注并列定义

### 类比推理（三大类词间关系，横向优于纵向）

- 考查形式 ★★★★：两项式/三项式（先找题干关系再匹配）、括号式（代入选项）
- 🔴 **三大类关系** ★★★★
	- 逻辑关系：全同、并列（矛盾/反对）、种属、交叉、顺承、因果、条件（充分/必要）；部分关系借文氏图判定
	- 言语关系：词义（近义/反义）、语法（偏正"的"/副+动"地"；动宾）
	- 经验常识：组成、功能、加工、职业、位置、目的、配套、引导
- 🟢 解题思路 ★★★：横向优于纵向、整体优于局部

### 事件排序

- 考查角度 ★★★★：时间顺序（需常识）、逻辑顺序（按事情发展先后）
- 🟢 两步：对比首尾句（排除不适合做首句的）→ 对比选项差异

## 三、数量关系（方程法是基础必备，赋值法、比例法是技巧型方法）

### 常用解题方法

- **数论基础** ★★★
	- 整除特性：所求量为整数+题干出现"除、整除、每、平均、分组"时考虑
		- 🟠 整除≠除尽：45÷1.5=30 是除尽不是整除
		- 判定：2/5看末一位；4/25看末两位；8/125看末三位；3/9看各位数字之和；11看奇偶位数字和之差
		- 合数拆互质数：能同时被两个互质数整除→能被其乘积整除
	- 奇偶特性：奇±偶=奇、奇+奇=偶、偶+偶=偶；奇×奇=奇、含偶则偶
	- 质合特性：除2外所有质数都是奇数
	- 约倍特性：最小公倍数、最大公约数
- **方程法** ★★★★★（使用频率最高）
	- 🟢 四步骤：找等量关系 → 设未知数 → 列方程 → 解方程
	- 找等量关系：文字标志（相等、共、比、倍、之和、之差、之积）+ 基本公式
	- 设未知数技巧：直接设所求量 / 设中间量；设小不设大、根据比例倍数设（避免分数小数）
	- 不定方程（未知数个数>独立方程个数）：正整数范围用代入排除+奇偶/整除/尾数特性；任意范围用赋0法（令系数最复杂的未知数为0）
- **比例法** ★★★
	- 三种能力：化简（"分母是自己的，分子是别人的"）、统一（找不变量→统一为最小公倍数份数→同比例变化）、计算（明确一份对应的实际量）
- **赋值法** ★★★★
	- 🟢 两类环境：①题干无实际量，数据均为比例/分数/倍数/百分数；②C=A×B关系且三个量只知其中一个的实际值
- **十字交叉法** ★★★
	- 适用：平均数、比重、浓度、利润率等比例混合
	- 🟠 前提：分子能相加、分母能相加才能混合
	- 结论：部分比例的分母之比 = 交叉作差之比（大减小）；(r-b)/(a-r) 最常用

### 常考题型（九大题型）

- **等差数列** ★★★★
	- 通项：an=a1+(n-1)d；推论：an-am=(n-m)d
	- 中项求和：奇数项=中间项×n；偶数项=中间两项和×项数一半
- **经济利润** ★★★★
	- 🔴 利润=售价-成本=成本×利润率；成本=售价÷(1+利润率)；利润率=利润÷成本×100%
	- 打几折=折后售价÷折前售价×10
	- 方法选择：实际量多用公式法；等量关系明显用方程法；只有比值关系/单一实际量用赋值法
	- 分段计费：每段分别计费（水电费/停车费/托运费）
- **工程** ★★★★★
	- 🔴 W=P×T（工作总量=效率×时间）
	- 合作工程赋值：给定时间型→赋总量为最小公倍数；效率制约型→赋效率为比例数据；效率相同型→赋效率均为1
	- 交替工程：算最小工作周期及周期效率 → 总量÷周期效率=完整周期数……余量
- **行程** ★★★★
	- 🔴 S=V×T；路程一定时速度与时间成反比
	- 相遇：路程和=速度和×时间（同时异地相向）
	- 追及：路程差=速度差×时间（同向）
	- 环形相遇：路程和=跑道周长；第n次相遇共跑n个周长
	- 环形追及：路程差=跑道周长；第n次追上多跑n周
	- 牛吃草：Y=(N-X)×T（原有草量=（牛吃速度-草长速度）×天数）；🟠 排水/排队检票/资源开采也是牛吃草
- **排列组合** ★★★
	- 计数原理：分类相加、分步相乘
	- 排列（有顺序）/组合（无顺序）
	- 🟢 四方法：枚举法（选项数据小）、优限法（有限制条件元素优先）、捆绑法（相邻→捆成整体再排内部）、插空法（不相邻→先排其他再插空，两边也算空）
- **古典概率** ★★★★
	- 特征：结果有限、等可能
	- 🔴 P(A)=事件A包含的等可能样本数÷总的等可能样本数（0≤P≤1）
	- 独立事件：分类相加、分步相乘
- **几何** ★★★★
	- 面积：三角形=底×高÷2、菱形=对角线乘积÷2、梯形=(a+b)×h÷2、圆=πr²、扇形=nπr²/360
	- 勾股：a²+b²=c²；常用勾股数（3,4,5）（6,8,10）（5,12,13）
	- 特殊直角三角形：30°→1:√3:2；等腰直角→1:1:√2
	- 体积：圆柱=πr²h、圆锥=πr²h/3、球=(4/3)πr³
- **最值** ★★★
	- 和定最值：求最大让其他尽量小，求最小让其他尽量大
	- 最不利原则："至少…才能保证"→保证数=最不利数+1
- **容斥** ★★★
	- 二者：I=A+B-A∩B+M；"只A只B"用文氏图
	- 三者：I=A+B+C-两两交集+三重交集+M；给"只属于两项"用：I=A+B+C-只两项-2×三重交集+M
	- 容斥极值：两者交集最小=A+B-I；三者=A+B+C-2I

## 四、资料分析（核心思想：列式越复杂选项差距越大，快速估算即可）

### 概念与列式（第16章）

- **一般增长** ★★★★★
	- 🔴 增长量=现期值-基期值=基期值×增长率=现期值/(1+增长率)×增长率
	- 增长率=增长量/基期值；基期值=现期值/(1+增长率)；现期值=基期值×(1+增长率)
	- 🟠 增长量有单位，增长率为百分数
	- 同比：以**最大**时间概念向过去循环一个周期；环比：以**最小**时间概念
- **间隔增长** ★★★
	- 🔴 间隔增长率 R=r₁+r₂+r₁×r₂
	- 间隔基期值=现期值/(1+R)
	- 🟠 百分数是率，百分点是量（两个百分数作差的单位）
	- 增速表述换算：上升→上年=现期-百分点；下降→上年=现期+百分点；降幅扩大→加；降幅收窄→减
- **年均增长** ★★★★
	- 年均增长量=(末期值-初期值)/n（n=增长次数=末期年-初期年）
	- 年均增长率：末期值/初期值=(1+r)ⁿ → r=ⁿ√(末期值/初期值)-1（需估算）
- **混合增长** ★★★
	- 🟢 三方法：居中不正中（整体介于部分之间）→ 偏移看基数（偏向基期值大的部分）→ 十字交叉法
	- 常见混合：进口+出口、城镇+农村、上半年+下半年、A与非A
- **比重** ★★★★★（难点：与平均数区分）
	- 识别："占"前为部分、"占"后为整体；"中"前为整体
	- 现期比重=部分(A)/整体(B)；基期比重=[A/(1+rA)]/[B/(1+rB)]或(A-a)/(B-b)
	- 🔴 判断比重变化：部分增长率>整体增长率→上升；<→下降；=→不变
	- 比重变化量=A/B×(rA-rB)/(1+rA)
- **平均数** ★★★★
	- 平均数=总量/份数；识别："每"后为份数单位；"均"后为总量、前为份数
	- 基期平均数=[A/(1+rA)]/[B/(1+rB)]
	- 判断变化同比重：分子增长率>分母增长率→上升
	- 平均数变化率=(rA-rB)/(1+rB)
- **倍数** ★★★
	- 是几倍=A/B；多几倍=是几倍-1；基期倍数=[A/(1+rA)]/[B/(1+rB)]

### 速算与比较（第17章）

- 🔵 核心思想：资料分析是选择题非填空题，选项必有差距，估算选出即可
- **尾数法** ★★★
	- 适用：加减运算、选项末几位不同
	- 🟠 三注意：末一位相同加减末两位；不够减需借位；小数位数不够补0
- **特殊数字法** ★★★★
	- 百分数→特殊分数：50%=1/2、33.3%≈1/3、25%=1/4、20%=1/5、16.7%≈1/6、14.3%≈1/7、12.5%=1/8、11.1%≈1/9、9.1%≈1/11、8.3%≈1/12、7.7%≈1/13、6.7%≈1/15、6.25%=1/16
	- A/(1+x%)×x%：当x%≈1/n时→A/(n+1)；A/(1-x%)×x%→A/(n-1)
	- 🟠 判断放缩：x%变大→选偏小项；x%变小→选偏大项
- **有效数字法** ★★★★★（乘除类占比约70%）
	- A/B型：分子不变、分母四舍五入保留三位
	- A±B型：看选项首个不同数位，取下一数位计算再四舍五入
	- A×B型：保留前两位，看第三位——全舍（均为0,1,2）、全进（均为8,9）、一进一舍（🟠 前三位小的先四舍五入，大的反向变化）
	- 多步乘除：先算乘法，再算除法
- **比较大小** ★★★★
	- 观察比较法：分母同分子大者大；分子同分母小者大；估首位
	- 同位比较法：分子间倍数关系大→分子大的大；分母间倍数关系大→分母大的小
	- 增长量比较（A/(1+r)×r型）：🟢 大大则大（A大r大都大）；一大一小看乘积（r相差不大时比A×r）
