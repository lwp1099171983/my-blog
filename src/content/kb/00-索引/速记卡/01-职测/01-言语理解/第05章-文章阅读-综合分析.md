## 本章任务
- 用片段阅读、逻辑填空、语句表达的综合能力，完成一篇 400–1600 字、2–9 段材料后的 5 道题目。
- 文章阅读本质是片段阅读、逻辑填空、语句表达三大类题型的综合，需迁移前三章的解题要点。
- 掌握"先题目后文章、先微观后宏观"的作答顺序，避免漫无目的通读浪费时间。

## 考点框架
- ⭐ 两类考点：微观类（局部信息）、宏观类（段落 / 全文主旨意图）。
- ⭐ 微观类五型：细节判断题、细节查找题、句子填空题、词语理解题、逻辑填空题。
- ⭐ 宏观类五型：主旨观点题、标题添加题、语段归位题、文章主题倾向判断题、下文推断题。
- ⭐ 本章三大特点：阅读量大、结构复杂；考查题型多元；难度相对适中（小于单独 5 个片段阅读或 5 个逻辑填空）。
- ⭐ 作答特点：面对篇幅长、段落多的文章，避免漫无目的阅读，按题型与定位要求筛选信息。
- ⭐ 能力要求：快速把握文章结构与各段作用；准确定位题目信息并比对选项；结合上下文理解句词与设空；概括段落与全文主旨、判断倾向；迁移三大类方法并控制阅读时间。
- ⭐ 重要性：理论精讲 ★★★★（考查难度低、考查频率★★★★）；全国事业单位联考 B 类及北京、天津、河南等需关注。

## 核心判定
- 🔴 微观类：①细节判断——两种形式：选项与原文比对直接定正误、判断是否为合理推断，考查最多；②细节查找——定位并概括指定内容，较简单；③句子填空——某段中设空、依上下文选；④词语理解——借所在句 / 段理解词义（最小单位考查）；⑤逻辑填空——结合设空处上下文语境推断。
- 🔴 宏观类：①主旨观点——两种形式：概括部分段落主旨、把握全文观点；②标题添加——理解主旨并合第一章方法；③语段归位——给定句 / 段选合适位置；④主题倾向——判断全文意图；⑤下文推断——据已有信息推下文，与前面题型最大区别是"推文章之外"（考查较少）。
- 🔴 语段归位三步：①定关键信息（主题词、关联词、指代词）；②快速定位相关内容；③分析前后句间关系定位置。

## 解题步骤
- 🟢 第一步·看题目，画关键，定题型：勾画题干关键信息（具体段落、话题对象、否定式问法），判定微观 / 宏观，定作答思路。
- 🟢 第二步·读文章，做标记，定位置：①标记段落顺序，边读边勾画关键词（关联词 / 指代词 / 总结词）、关键句（首尾句 / 观点结论句）、关键段（首尾段 / 承上启下段）；②逐段概括大意并批注。
- 🟢 第二步标记细化：关键词勾画关联词 / 指代词 / 总结词；关键句勾画首尾句、观点结论句（如科技发现、推测、成果）；关键段勾画首尾段与承上启下段。
- 🟢 第三步·做题目，先微观，后宏观：①微观题边读边解，坚持"遇空填空、遇排则排"；针对全文的细节判断跨段难定位，建议整体读完后答；②宏观题需整体把握、综合理解后解答。
- 🟢 时间控制：文章阅读难度小于单独 5 个片段 / 填空，宜作为言语得分点，避免因畏难而放弃整篇。

## 易混辨析
- 🟠 微观 vs 宏观：微观考局部信息（细节、填空、词语），宏观考段落 / 全文主旨意图。
- 🟠 细节判断 vs 细节查找：判断是比对正误 / 合理推断，查找是定位并概括（更简单）。
- 🟠 句子填空（文章段中设空）vs 语句表达填空（独立文段）：前者依托长文上下文，后者是孤立语段。
- 🟠 主旨观点两形式：概括部分段落主旨 / 把握全文观点，勿混。
- 🟠 语段归位 vs 下文推断：前者把给定内容放回已有文章，后者据文章推"接下来"的内容。
- 🟠 标题添加 vs 主旨观点：标题添加既考主旨理解也考标题特点，需回第一章方法，不单看主旨。
- 🟠 细节判断"比对" vs "合理推断"：前者直接定正误，后者要判断推导是否成立，勿把推断当原文。
- 🟠 细节查找（简单，定位并概括）vs 细节判断（考查最多，比对 / 推断）：前者找得到即可，后者要判定对错。
- 🟠 微观题"边读边解" vs 宏观题"整体后解"：微观可遇空填空、遇排则排，宏观须读完对应段 / 全文再答。
- 🟠 语段归位三步走漏步：未先定关键信息（主题词 / 关联词 / 指代词）就定位，易放错位置。
- 🟠 主旨观点（部分段落）vs（全文）：问"这段文字意在说明"多指局部，问"文章主旨"指全文，审题先区分范围。
- 🟠 词语理解（最小单位，只释词）vs 句子填空（填整句）：解题粒度不同，勿混。
- 🟠 主题倾向 vs 主旨观点：倾向重作者态度 / 意图走向，主旨重核心观点，选项常以局部代替全文。
- 🟠 先微观后宏观：遇空填空、遇排则排可边读边做；全文性细节判断需后置到通读后。
