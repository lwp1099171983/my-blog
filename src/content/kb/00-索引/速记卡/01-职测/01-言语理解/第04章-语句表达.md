## 本章任务
- 掌握句子排序、句子填空、病句辨析三类题型的判定标志与解题原则。
- 排序题抓"首句 + 句间标志"快速定序；填空题保话题与句间关系一致；病句题用主干枝叶 + 关键词法辨析八类语病。

## 考点框架
- ⭐ 三节：第一节 句子排序题、第二节 句子填空题、第三节 病句辨析题。
- ⭐ 重要性：句子排序题 ★★★★（考查频率中）、句子填空题 ★★★★（考查频率中）、病句辨析题 ★★★★★（考查频率低）。
- ⭐ 病句辨析在全国事业单位联考不考；北京、天津、福建、深圳等非联考区域需关注。
- ⭐ 句子排序是言语中技巧性较强的题型，不必逐字精读，靠标志快速定序。

## 核心判定
- 🔴 不适合做首句的三种句子：①含指代词且指代不明 / 论述对象不明的；②以转折词、因果词、总结词开头的；③选项同时有"引出话题"和"具体描述"时，具体描述的句子。
- 🔴 适合做首句的句子：背景介绍、概念介绍、引用等（引出话题或概括全文）。
- 🔴 句间五类标志：①指代词——所在句在含所指对象的句子之后；②关联词——定逻辑关系顺序；③顺序词（时间从古至今、空间渐进）——定先后；④总结词——多置尾句；⑤重复词——同话题捆绑，按引出→解释→应用排列。
- 🔴 句子填空两原则：①话题一致（填入句陈述对象与文段一致）；②句间关系一致（前后逻辑连贯）。
- 🔴 设空位置作用：段首位总领 / 引出 / 背景铺垫；段中位承上启下；段尾位得出结论或总结前文。
- 🔴 病句八类：用词不当、搭配不当、语序不当、成分残缺、成分赘余、表意不明、结构混乱、不合逻辑。
- 🔴 多重定语语序：领属 / 时间 / 处所短语 + 指称 / 数量短语 + 动短语 + 形短语 + 名短语；带"的"在前。
- 🔴 多重状语语序：目的 / 原因介宾 + 时间 / 处所 + 范围 / 对象 + 情态 / 程度；对象介宾紧挨中心语。
- 🔴 关联词与主语错位：前后主语一致，主语在关联词前；不一致，主语在关联词后。

## 解题步骤
- 🟢 排序三步：①观察选项定首句（排除不适合作首句项）；②读材料提取标志（指代 / 关联 / 顺序 / 总结 / 重复词）；③前两步未定再梳理句间关系、按语义归类定整体顺序。
- 🟢 填空三步：①看设空位置（首 / 中 / 尾）明确作用；②依话题一致、句间关系一致筛选；③代入验证前后连贯。
- 🟢 病句两步法：①主干枝叶梳理——先提主干（主谓宾）查成分残缺、搭配不当，再查修饰语（定状补）与中心语；②关键词语检查——见下表。
- 🟢 关键词语检查表：

| 关键词类型 | 提示错误类型 |
| 并列短语 | 搭配是否全对、并列是否交叉 / 包含、顺序是否合逻辑 |
| 关联词语 | 搭配、逻辑、位置是否正确 |
| 否定词 | 多重否定不当 |
| 数量短语 | 成分赘余、表意不明 |
| 两面词 | 两面对一面 |
| 介词 | 主语残缺、主客颠倒 |
| 代词 | 指代不明造成歧义 |
| 多音多义词 | 不同读音造成歧义 |
| 多重定语状语 | 语序不当 |
| 固定句式 | 句式杂糅 |

## 易混辨析
- 🟠 不适合首句 vs 适合首句：前者是"具体描述、指代词开头、转折因果总结词开头"，后者是"背景 / 概念 / 引用"引出话题。
- 🟠 指代词捆绑 vs 重复词捆绑：指代词句在所指对象句之后；重复词是同一话题捆绑并按引出→解释→应用排。
- 🟠 总结词置尾 vs 顺序词置中：总结词多放尾句收束，顺序词（时间 / 空间）只定局部先后。
- 🟠 搭配不当四细分：主宾、主谓、谓宾、定状语与中心语，均查主干 / 修饰与中心是否搭得上。
- 🟠 语序不当四细分：多重定语、多重状语、定状错位、关联词与主语错位。
- 🟠 成分残缺 vs 成分赘余：前者缺主 / 谓 / 宾必要成分，后者多词重复啰嗦。
- 🟠 指代不明 vs 歧义：指代不明是代词对象多解；歧义是修饰对象多、多义词、停顿不同导致多解。
- 🟠 两面对一面 vs 否定不当：两面词（是否 / 能否）需前后呼应；多重否定词易把意思说反。
