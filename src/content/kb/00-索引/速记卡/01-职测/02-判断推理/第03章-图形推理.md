## 本章任务
把"图形特征 → 规律方向"的对应关系练成条件反射：先判图形相似还是相异，再看自身特性、数量、元素分布，最后处理立体与平面拼接；靠特征有方向地分析，不靠灵感。

## 考点框架
- ⭐ 四节：图形相似（位置规律、叠加规律）/ 图形相异（图形特性、数量规律、元素分布）/ 立体图形（六面体、四面体、三视图、截面图、立体拼接）/ 平面拼接（常规、小方格型）
- ⭐ 重要性：图形相似 ★★★★★（高频）、图形相异 ★★★★★（高频）、立体图形 ★★★（中）、平面拼接 ★★★（低）
- ⭐ 考查形式：顺推型、类比型、九宫格型、分类分组型、条件型
- ⭐ **特征 → 方向（本章最该背的一张对照）**
  - 图形相似 + 组成元素完全相同 → 位置规律
  - 图形相似 + 组成元素同中有异 → 叠加规律
  - 图形相似度低 + 自身特性明显 → 图形特性
  - 图形相似度低 + 自身无明显特性 → 数量规律
  - 图形相似度低 + 每个图形由多个元素组成 → 元素分布

## 核心判定
- 🔴 位置规律：**平移**（方向：上下左右、顺/逆时针；距离：等距、距离依次递增）/ **旋转**（方向：顺/逆时针；角度 30°、45°、60°、90°）/ **翻转**（左右翻转＝沿竖直轴对折，上下翻转＝沿水平轴对折）
- 🔴 叠加规律：直接叠加（保留所有元素）/ 去同求异 / 去异求同 / 特殊运算（常考黑白运算）
- 🔴 图形特性三项：**对称**（轴对称：对称轴数量、方向；中心对称；轴对称＋中心对称；对称轴与原图中点、线、面的关系；对称轴之间的关系）/ **直曲**（全直线图形、全曲线图形、有直有曲图形）/ **开闭**（开放图形＝内部无封闭区间，封闭图形＝内部有封闭区间）
- 🔴 数量规律五项：**点**（所有交点数；特殊交点：十字交点、直曲交点、切点、内部交点、外部交点）/ **线**（直线数、曲线数、图形笔画数、汉字笔画数）/ **面**（封闭区间＝封闭的白色区域；部分＝连在一起的算一部分）/ **元素**（小元素的种类数、个数）/ **角**（锐角 0°-90°、直角 90°、钝角 90°-180°）
- 🔴 元素分布：**元素遍历**（同一遍历：同一元素在每个图形中都出现；元素传递：前一个图形把某部分元素传给下一个）/ **相对位置**（相离、相交、相接——点相接/线相接；排列位置：相对、相邻；结构位置：左右、上下、内外；平行、垂直；小元素在特殊位置）
- 🔴 六面体解题原则：**图案在外侧**（折成"包饺子"把图案折进内侧就是错的）
- 🔴 六面体三条技巧：① **相对面不相邻** ② **相邻面的相对位置不变** ③ 相邻面靠**公共边**判定
- 🔴 相对面判定（2 条）：同行（列）中间隔一个面的两个面为相对面；"Z"字形两端的两个面为相对面
- 🔴 公共边判定（3 条）：展开图中相挨的边；呈直角的两条边；同一行（列）连着四个面时两头的两条边
- 🔴 四面体公共边（3 条）：挨在一起的边；处在同一条线上的两条边；展开图为平行四边形时两侧短边互为公共边。公共边不好判时用**箭头法**辅助判相对位置
- 🔴 三视图：主视图（前→后）、俯视图（上→下）、左视图（左→右）；最外框挡住内部线条时，被挡住的线条**画虚线或不画**
- 🔴 截面图三原则：① 截面图边数 ≤ 立体图形的面数 ② 曲线必截于曲面 ③ 平行面必截平行线
- 🔴 正六面体可截图形：三角形——可截锐角三角形（含等边、等腰），**截不出直角与钝角三角形**；四边形——正方形、长方形、平行四边形、菱形、梯形，**截不出直角梯形**；五边形——可截，但一定有 2 对平行线，**不可能是正五边形**；六边形——可截，一定有 3 对平行线
- 🔴 正四棱锥可截：锐角/直角/钝角三角形、正四边形、任意四边形、任意五边形；圆柱可截长方形、鼓形、"半圆"形（有直线）与圆形、椭圆形（无直线）
- 🔴 立体拼接原则：**凹凸一致**（有凸必配凹）、**"个数"相等**（小方块个数相加等于组合图形）；思路是**分层讨论**
- 🔴 平面拼接方法：常规型用特殊线条法、平行线条拼接法；小方格型用最大面定位法
- 🟢 关键纪律：规律必须在**所有图形中一致成立**才算规律，不能凭某一个图形的特征就作答

## 解题步骤
1. **先定大方向**：图形相似（元素同源）／图形相异（彼此不搭）／立体与拼接
2. **相似**：元素完全相同 → 试平移、旋转、翻转（盯方向与距离/角度）；同中有异 → 试直接叠加、去同求异、去异求同、黑白运算
3. **相异**：先看对称、直曲、开闭；都不明显 → 数数量（点→线→面→元素→角，一个一个数过去）；多元素 → 看遍历与相对位置
4. **六面体**：① 确定选项立体图形的三个面在展开图中对应的面 ② 判断是否出现"相对面相邻"，有则优先排除 ③ 再验相邻面的公共边与相对位置是否正确
5. **四面体**：① 确定两个面对应的展开面 ② 比对公共边与展开图是否一致，不一致即排除 ③ 直接判公共边困难时用箭头法辅助
6. **截面图**：先把组合体拆成简单立方体，再对照"可截/不可截"清单排除选项
7. **立体拼接**：用"凹凸一致"先配形状，用"个数相等"排项，再分层讨论逐层拼
8. **平面拼接**：① 先看清问法是否允许旋转、翻转 ② 常规题用特殊线条法、平行线条拼接法 ③ 小方格型用最大面定位法（最大面积先靠选项边缘定位），也可数方格个数排除

## 易混辨析
- 🟠 平移 vs 旋转：先看元素**朝向**有无变化——朝向不变是平移，按固定角度改变朝向是旋转
- 🟠 左右翻转 vs 上下翻转：沿竖直轴对折＝左右翻转（左右互换），沿水平轴对折＝上下翻转（上下互换）
- 🟠 相对面 vs 相邻面：相对面在立体图中**永远不会相邻**；"同行（列）隔一个"和"Z 字两端"两条要能一眼认出
- 🟠 特殊线条法 vs 平行线条拼接法：某条线在其他图形里找不到平行线 → 这条线必成选项轮廓（特殊线条法）；两条平行且等长的线可优先拼合（平行线条拼接法）
- 🟠 立体拼接"凹凸一致"是形状判据、"个数相等"是数量判据，两者要同时用，不能只看一个
- 🟠 最大面定位法只用于小方格型平面拼接，常规多边形拼接不要用
- 🟠 看清问法：问"能截出/能折成"还是"不可能"，求"不可能"时优先用边数上限、平行面、曲线三条原则快速排除
- 🟠 图形特性 vs 数量规律：特性明显先看特性，**别一上来就数数**，数数是最后一条路
