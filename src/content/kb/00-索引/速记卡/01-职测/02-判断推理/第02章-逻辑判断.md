## 本章任务
按"必然性 / 可能性"两条主线分流：必然性推理靠"先翻译成符号、再套矛盾与推理规则"，可能性推理靠"分析论证三要素、按削弱加强角度比力度"；全程守住逻辑严谨性——题干没说的都不确定。

## 考点框架
- ⭐ 八大节：直言命题 / 联言、选言命题 / 假言命题 / 朴素逻辑 / 论证基础 / 削弱·加强型 / 解释·结论·评价型 / 综合判断推理
- ⭐ 重要性：假言命题 ★★★★★（高频）、朴素逻辑 ★★★★★（高频）、论证基础 ★★★★★、削弱加强 ★★★★★；直言命题 ★★★、联言选言 ★★★（频次低，但综合性强、是可能性推理的基础）
- ⭐ 两条主线
  - **必然性推理**＝翻译 + 矛盾/推出/反对/推理规则，答案必然成立
  - **可能性推理**＝先找结论与论据，再按削弱、加强角度和力度比较选最优
- ⭐ 综合判断推理：一段材料带 2-3 问，本质是上述题型的组合，先看问题再回材料定位

## 核心判定
- 🔴 直言矛盾（"并非"法）：所有A是B ↔ 有些A非B；所有A非B ↔ 有些A是B；某个A是B ↔ 某个A非B
- 🔴 直言反对：上反对「所有A是B / 所有A非B」至少一假；下反对「有些A是B / 有些A非B」至少一真
- 🔴 直言推出：所有A是B → 某个A是B → 有些A是B（"所有A非B → 某个A非B → 有些A非B"同理）
- 🔴 联言 p且q：一假则假、全真则真；真→两支全真；假+一支真→另一支必假；矛盾＝非p或非q
- 🔴 相容选言 p或q：一真则真、全假则假；假→两支全假；真+一支假→另一支必真；矛盾＝非p且非q
- 🔴 不相容选言 要么p要么q：有且只有一支真才真；真→一支真、另一支必假；矛盾＝（p且q）或（非p且非q）
- 🔴 假言翻译：充分条件（如果…那么/就、若…则、只要…就、要想…必需）→ **前推后**；必要条件（只有…才、除非…否则不）→ **后推前**
- 🔴 假言推理：**肯前必肯后、否后必否前**；否前、肯后推不出必然结论
- 🔴 假言矛盾：p→q ↔ p且非q（真假话题里常作矛盾源）
- 🔴 三段论五个标准式：所有A是B+所有B是C→所有A是C；有些A是B+所有B是C→有些A是C；所有A是B+所有B非C→所有A非C；有些A是B+所有B非C→有些A非C
- 🔴 三段论有效标准（5 条）：只有三个概念（A/B/C）/ 每个概念均出现两次 / 前提中至少有一个"所有" / 结论出现"有些"则前提中一定有"有些" / 结论为否定时前提中含奇数个否定词
- 🔴 三段论等价换位：有些A是B＝有些B是A；所有A非B＝所有B非A；所有A是B＝所有非B非A
- 🔴 论证三要素：结论（核心观点）、论据（支持观点的依据）、论证联系（论据与结论之间的主观联系）
- 🔴 削弱三角度：削结论（**优先**）/ 断论证联系 / 削论据；加强三角度一一对应，也是先想加强结论
- 🔴 前提型：前提＝**必要条件**，与"一般加强"不同；两法是搭桥法、反向验证法
- 🔴 力度比较（5 条）：本质＞现象、必然＞可能、量大＞量小、直接＞间接、综合＞单一
- 🟢 找结论标志词：因此、所以、认为、相信、宣称、说明、表明、意味着、预测、推测、由此可知、据此推出、得出结论
- 🟢 论证过程 5 型：论据→结论 / 多论据→结论 / 论据→多结论 / 论据→中间结论→最终结论 / **只有结论**（无依据，只能削结论、加结论）
- 🟢 文氏图约定："所有"用圈表示，"有些"用点表示

## 解题步骤
1. **真假话题**（"只有 N 句真/假"）：一找（先找矛盾命题；无矛盾再找反对命题）→ 二绕（绕开它，判定其他命题真假）→ 三回（回到矛盾/反对定真假）
2. **直言"知真求真"**（据此可以推出）：① 翻译题干 ② 应用推出关系
3. **假言题**：① 用联结词把题干翻译成 p→q ② 用"肯前必肯后、否后必否前"逐项验算，凡是否前/肯后的表述一律不选
4. **三段论**：结论型→画文氏图后结合规则判选项；前提型→用 5 条有效标准排除错误选项
5. **朴素逻辑**：先找突破口——确定条件（能得出确定信息）、关联条件（题干中出现次数最多的元素）→ 选项把对应关系给得全用**代入排除法**；真假话不确定用**假设法**（假设后与题干冲突即假设不成立）；元素对应用**列表法**、位置关系用**画图法**
6. **削弱/加强题**：先剔除背景、概念介绍等不参与论证的内容，提炼论据与结论 → 先试"削/加结论" → 论据与结论**概念不一致**时想"断/建联系"（问"削弱论证"多半考这个）→ 论据是某人观点、调查结果、实验发现时想"削/加论据" → 两项都能削/加时用力度五条比
7. **前提型**：搭桥法（找论据和结论中不同的两个概念 B、C，建立二者联系）；反向验证法（先否定选项，再代入题干，若结论不成立，则该选项是必需的前提）
8. **解释型**：① 找到要解释的现象 ② 分析现象产生的原因；**结论型**：① 读题干 ② 把选项代入题干定位分析；**评价型**：① 分析题干与选项的推理形式（命题推理用 A/B/C 替换概念，论证则先找论据与结论）② 选形式一致的选项

## 易混辨析
- 🟠 矛盾 vs 反对：矛盾必一真一假；上反对至少一假（可同假）、下反对至少一真（可同真）。真假话题先数真假个数，再决定用矛盾还是反对
- 🟠 推出 ≠ 等价：所有→某个→有些 是单向推出，反向不成立；但"有些A是B＝有些B是A"是等价，要分清
- 🟠 相容选言 vs 不相容选言：p或q 允许同真；要么p要么q 排斥同真，两者的矛盾式完全不同
- 🟠 否前、肯后 无必然结论：只记"否后必否前"，不要把逆命题当成成立
- 🟠 前提型 vs 一般加强：前提是必要条件（否定后结论不成立）；一般加强只需让结论成立的可能性变大
- 🟠 削论证联系 vs 削论据：前者砍"论据→结论"的桥（概念/话题不一致时用）；后者打论据本身（论据为某人观点、调查、实验时用）
- 🟠 只有结论型：题干没有论据，只能从削/加结论下手，不要去建联系
- 🟠 问"不能推出/不一定为真"时，正确项往往是"无法确定"，不要误选与题干明显相反的项
