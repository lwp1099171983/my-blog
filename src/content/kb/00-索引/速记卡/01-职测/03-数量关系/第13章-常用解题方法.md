## 本章任务
- 五大方法分流：基础方法方程法（覆盖最广、必掌握）＋技巧型方法赋值法/比例法（提速）＋数论基础（整除/奇偶/质合/约倍）作速解筛选。
- 做题先判"什么题用什么方法"：有等量关系→方程法；纯比例无实际量或 C=A×B 只知一量→赋值法；多组比例/份数→比例法；比例混合→十字交叉；整数约束筛选项→数论特性。

## 考点框架
- ⭐ 五大块：数论基础 / 方程法 / 比例法 / 赋值法 / 十字交叉法
- ⭐ 重要性（讲义导学）：方程法 ★★★★★（高频、使用率最高且上升）；赋值法 ★★★★；数论基础 / 比例法 / 十字交叉 ★★★
- ⭐ 数论基础四特性：整除 / 奇偶 / 质合 / 约倍，是方程与技巧法的底层筛选工具

## 核心判定
- 🔴 方程法信号：题干存在等量关系（出现"相等、共、比、倍、之和、之差、之积"，或基本公式 路程=速度×时间、工作总量=效率×时间、利润=售价−成本）→ 优先方程法（P135）
- 🔴 赋值法信号①：全部数据为比例/分数/倍数/百分数、无实际量 → 赋值法（P143）
- 🔴 赋值法信号②：存在 C=A×B 关系（总价=单价×数量、路程=速度×时间、销售金额=价格×销量）且只知一个实际量 → 赋值法（P144）
- 🔴 比例法信号：题干出现比例/分数/百分数描述，或多组比例需统一 → 比例法（P140）
- 🔴 十字交叉信号：多个部分比例能混合（分子可加、分母可加，如平均分、浓度、比重、利润率）→ 十字交叉（P146）
- 🔴 整除法信号：所求量为整数，且出现"除、整除、每、平均、分组"等字眼 → 用整除特性筛答案（P132）
- 🔴 整除判定速记：2/5 看末一位；4/25 看末两位；8/125 看末三位；3/9 看各位数字之和；11 看奇位和与偶位和之差（P131-132）
- 🔴 合数判定：拆成互质两数乘积，能同时被两数整除则被该合数整除（如 55=5×11，5 与 11 互质则被 55 整除）（P132）
- 🔴 奇偶特性（不定方程）：系数一奇一偶时，结合 奇±偶=奇、奇×奇=奇、偶×任何=偶 排除选项（P137）
- 🔴 尾数特性（不定方程）：系数尾数 0 或 5 时，5×偶尾 0、5×奇尾 5；遇到尾 5 先判奇偶再结合尾数（P137）
- 🔴 质数：>1 且除 1 和本身无其他因数；除 2 外所有质数都是奇数（P133）
- 🔴 约倍特性：公倍数（c 同是 a、b 的倍数）、公约数（d 同是 a、b 的约数）；分别取最小/最大（P133）
- 🔴 十字交叉结论：部分比例分母之比 =（整体比例−另一部分比例）：（该部分比例−整体比例），作差均取"大减小"（如男均78、女均85、全班80 → 男:女=(85−80):(80−78)=5:2）（P147）
- 🔴 比例统一关键：先找"同时存在且未发生变化的不变量"作基准，统一为相同份数（取最小公倍数）再同比例变化（P141）

## 解题步骤
1. 🟢 方程法四步：找等量关系→设未知数→列方程→解方程
2. 🟢 设未知数技巧：直接设所求量；所求量不在等量关系中则设中间量；多未知量且数量关系明显→设小不设大；比例/百分数描述→化比例按系数设（P135-136）
3. 🟢 解方程：一元一次（去分母→去括号→移项→合并→系数化1）；二元一次（加减消元、代入消元）（P136）
4. 🟢 不定方程 ax+by=c（未知数个数>独立方程个数）：正整数范围用代入排除＋奇偶＋整除＋尾数四法；任意范围用赋0法（令最复杂系数为0消元）（P137）
5. 🟢 比例法三步：化简（分数/百分数/倍数→最简比，"分母是自己的，分子是别人的"）→统一（找不变量，统一为相同份数如最小公倍数）→计算（一份对应实际量）（P140-142）
6. 🟢 比例化简：A 是 B 的 n 倍→A:B=n:1；A 比 B 多 n 倍→A:B=(n+1):1；百分数先转分数再定基准参照（P140-141）
7. 🟢 赋值法三步：判断能否赋值→确定赋值对象及数值→结合题干关系求解（P143）
8. 🟢 十字交叉三步：确认比例可混合→列部分与整体比例→交叉作差取最简比得分母之比（P146-147）

## 易混辨析
- 🟠 整除 vs 除尽：整除是整数间无余数；除尽是数字间无余数（含小数，如 45÷1.5），整除判定不适用于除尽关系（P131）
- 🟠 设小不设大 vs 按倍数设：多未知量有明显数量关系用"设小"；比例/百分数描述用"按比例系数设"避免小数（P135-136）
- 🟠 赋值法两类环境别混：纯比例无实际量 vs C=A×B 只知一量，二者都靠"赋一个自由量"简化计算（P143-144）
- 🟠 比例统一 vs 比例计算：先"统一"让每份实际量相同，再"计算"一份对应值；多组比例不同维度不统一会算错（P141）
- 🟠 十字交叉"大减小"：交叉作差一律大数值减小数，避免符号出错（P147）
- 🟠 不定方程四法优先级：所求单一未知数先用代入排除；系数一奇一偶用奇偶、系数有公因数用整除、系数尾 0/5 用尾数（P137）
