## 本章任务
- 数字推理不是盲目计算，先按数列特征判断规律类型，再找具体运算；规律必须能解释全部已知项，不能只凭局部巧合定答案。
- 排查顺序：直接规律→作差→作和→作商/倍数→分组→次方或特殊形式拆分。

## 考点框架
- ⭐ 十类题型：基础数论 / 差数列 / 和数列 / 倍数数列 / 分数数列 / 分组数列 / 次方数列 / 根式数列 / 图形数列 / 小数数列
- ⭐ 能力要求：识别单调性、变化幅度、特殊数字与特殊形式；据特征选作差/作和/作商/分组/拆分；验证规律覆盖全数列
- ⭐ 考场定位：全国事业单位联考无此题型，福建等非联考地区需关注

## 核心判定
- 🔴 六步法：看整体（单调/幅度/排列）→看基础（自然数、质数、平方、等差、等比）→看运算（作差/作和/作商/倍数）→看特殊形式（分数拆分子分母、根式看根号内外、小数拆整数小数、图形看横纵中心）→找修正项（乘除以平方后是否要加减修正）→验规律（多组已知项验证）
- 🔴 数列类型 → 判定特征 → 首选运算

| 数列类型 | 判定特征 | 首选运算 |
| --- | --- | --- |
| 差数列 | 基本单调、变化幅度小，或原数列无明显规律 | 作差（一级/多级/作差结合原数列构造网络） |
| 和数列 | 幅度小、不单调、小数字较多 | 作和（相邻2/3项递推或和成基础数列，可加修正） |
| 倍数数列 | 基本单调、幅度较大，局部倍数明显 | 作商/倍数递推（可带修正项） |
| 分数数列 | 项多为分数 | 先四则，无规律再拆分子、分母 |
| 分组数列 | 较长、不单调、奇偶交错，或多位数易拆分 | 间隔分组/分段分组/整数拆分 |
| 次方数列 | 陡增，或数字接近平方/立方 | 次方规律＋修正（指数变/底数变/同变） |
| 根式数列 | 含根号 | 化简后看根号内、外分别规律 |
| 小数数列 | 含小数点 | 拆整数与小数部分分别找规律 |
| 图形数列 | 图形排布 | 横向/纵向/中心与周边关系 |
| 基础数论 | 出现质数、平方、立方、2的幂等特殊数 | 联想质合、约倍、次方性质 |

- 🔴 基础数论重点：熟记自然/奇/偶/质/合/和/平方/立方/等差/等比/积/循环数列；见特殊数字主动联想其质合、次方、约倍性质
- 🔴 考场口诀：小幅先作差，低数先作和；倍增看作商，陡增看次方（配合"分数拆分子分母，长串奇偶分组看；根式小数先拆开，图形横纵中心验"）

## 解题步骤
1. 🟢 看整体：先判单调性与幅度，决定优先作差还是作商
2. 🟢 看基础：联想自然数、质数、平方、立方、等差、等比等基础数列
3. 🟢 看运算：依次尝试作差、作和、作商、倍数关系
4. 🟢 看特殊形式：分数看分子分母；根式看根号内外；小数拆整数与小数；图形看横纵及中心
5. 🟢 找修正项：检查乘/除/平方后是否还需加减修正
6. 🟢 验规律：至少用多组已知项验证，确保规律覆盖全数列

## 易混辨析
- 🟠 分数数列别机械拆：不要只看分子或只看分母；出现重复数字或明显运算关系时，应结合分子、分母整体观察
- 🟠 根式先化简后比较：如 √12=2√3，统一形式再找根号内外规律
- 🟠 局部巧合不算规律：必须能解释全部已知项，不能只依据前几项巧合定答案
- 🟠 差与和的选择：幅度小且单调→作差；幅度小且不单调、小数字多→作和；幅度大、局部倍数明显→作商
