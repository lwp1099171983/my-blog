## 本章任务
- 把"题干时间参照、比较对象、所求指标"先拆清，再决定套哪个公式；资料分析重理解材料而非死背公式。

- 每类做到"识别问法关键词 → 选调公式 → 列式（必要时只判升降不计算）"。

## 考点框架
- ⭐ 七节：①一般增长 ②间隔增长 ③年均增长 ④混合增长 ⑤比重 ⑥平均数 ⑦倍数
- ⭐ 重要性（讲义标注）：一般增长 ★★★★★、比重 ★★★★★（高难度高频）；年均增长 ★★★★、平均数 ★★★★（高频）；间隔/混合/倍数 ★★★（中频）
- ⭐ 必背四组核心公式族：增长族（量/率/基期/现期）、间隔族（R 与间隔基期）、比重族（现期/基期/变化量）、平均数族（现期/基期/变化量/变化率）；倍数族（是几倍/多几倍/基期倍数）
- ⭐ 两个"只判不算是送分点"：比重变化、平均数变化都只看 rA 与 rB 大小即可定升降
- ⭐ 混合增长不套复杂公式，用"居中不正中 + 偏移看基数 + 十字交叉"

## 核心判定
- 🔴 概念 / 公式（分数形式照抄） / 问法关键词 三列对照：

| 概念 | 公式（含分数形式） | 问法关键词 |
|---|---|---|
| 增长量 | 增长量 = 现期值 − 基期值 = 基期值×r = 现期值/(1+r)×r | 增加/增长多少（实际量、有单位） |
| 增长率 | r = 增长量/基期值 = (现期−基期)/基期×100% = 现期/基期 − 1 | 增长百分之几、增速、增幅 |
| 基期值 | 基期值 = 现期值/(1+r) = 现期值 − 增长量 | 求过去某年的值 |
| 现期值 | 现期值 = 基期值×(1+r) = 基期值 + 增长量 | 求现在/未来某年的值 |
| 间隔增长率 | R = r₁ + r₂ + r₁×r₂ | 隔一年、较 N−2 年增长百分之几 |
| 间隔基期值 | 间隔基期值 = 现期值/(1+R) | 求 N−2 年的值 |
| 年均增长量 | a = (末期值 − 初期值)/n（n=增长次数） | 年均增长约多少（量） |
| 年均增长率 | r = (末期值/初期值)^(1/n) − 1 ≈ (末期值/初期值 − 1)/n | 年均增长百分之几 |
| 现期比重 | 比重 = A(部分)/B(整体)×100% | 占…比重、…中所占比重 |
| 基期比重 | A/B×(1+rB)/(1+rA)，或 (A−a)/(B−b) | 求某年占比 |
| 比重变化量 | 比重变化量 = A/B×(rA−rB)/(1+rA)（单位：百分点） | 占比上升/下降多少个百分点 |
| 现期平均数 | 平均数 = A(总量)/B(份数) | 平均每…多少 |
| 基期平均数 | A/B×(1+rB)/(1+rA)，或 (A−a)/(B−b) | 求某年平均 |
| 平均数变化量 | 平均数变化量 = A/B×(rA−rB)/(1+rA) | 平均…增加/减少多少 |
| 平均数变化率 | 平均数变化率 = (rA−rB)/(1+rB) | 平均…上升/下降百分之几 |
| 现期是几倍 | 是几倍 = A/B | A 是 B 的多少倍 |
| 现期多几倍 | 多几倍 = A/B − 1 | A 比 B 多多少倍 |
| 基期是几倍 | A/B×(1+rB)/(1+rA)，或 (A−a)/(B−b) | 求某年 A 是 B 几倍 |

- 🔴 增长率 ↔ 倍数（比较现期与基期时）：是几倍 = 现期/基期 = 1+r；多几倍 = r（即增长率本身）。陷阱：把"是几倍"当"多几倍"，或忘记 −1。
- 🔴 比重变化量 ↔ 百分点：比重变化量 = 现期比重 − 基期比重，结果单位是"百分点"（不是百分数）；与"百分数作差"单位一致（P189）。
- 🔴 百分点 ↔ 百分数：百分数是率（%）；百分点是两个百分数作差的单位。增长率 ± 百分点反推上年率（P190）：上升/提高→减、下降/减少/降低/回落→加；降幅扩大→加、降幅收窄→减。
- 🔴 混合增长三原则：① 居中不正中（整体增速介于各部分增速之间）② 偏移看基数（偏向基期值大的部分，越过中值靠近它）③ 十字交叉：A基期值:B基期值 = (r−rB):(rA−r)。
- 🔴 百分数与百分点定义（P189）：百分数"表示一个数是另一个数的百分之几，用 %"，是一个率；百分点"表示两个百分数之间作差结果的单位"。
- 🔴 同比与环比（P184）：同比按"最大时间概念"循环一期（2022年5月同比=2021年5月，季度同比=去年同季）；环比按"最小时间概念"循环一期（2022年5月环比=2022年4月，季度环比=上一季）。

## 解题步骤
1. 🟢 定时间：判现期/基期；同比（最大时间概念循环）还是环比（最小时间概念循环）；间隔/年均要数清期数 n（增长次数 = 末期−初期年数）。
2. 🟢 定对象与指标：区分部分/整体（比重）、总量/份数（平均数）、A/B（倍数）；找准分子 rA、分母 rB。
3. 🟢 选公式：问"量"→增长量/年均增长量/变化量；问"率"→增长率/比重/倍数/变化率；照上表套式，基期类优先用 (1+r) 型或 (A−a)/(B−b) 型。
4. 🟢 判变化（偷懒法）：比重、平均数只问升/降时，比 rA 与 rB——rA>rB 升、rA<rB 降、rA=rB 不变，无需算。
5. 🟢 混合增长：先"居中不正中"圈范围，再"偏移看基数"定偏向；选项仍模棱两可才上十字交叉求精确比。
6. 🟢 百分点换算：题干遇"上升/下降/扩大/收窄 XX 个百分点"，按 P190 四行规则反推上年增长率后再列式。

## 易混辨析
- 🟠 增长量 vs 增长率：增长量是实际增减的量（有单位，如万吨）；增长率是相对基期的百分数（%）。关系 r = 增长量/基期值。
- 🟠 同比 vs 环比：同比按"最大时间概念"循环（年→去年同月/同季）；环比按"最小时间概念"循环（月→上月、季→上一季）。别把一季度环比错当去年同期。
- 🟠 比重 vs 平均数：比重 = 部分/整体，结果百分数、无单位；平均数 = 总量/份数，单位为复合单位（吨/公顷、元/人）。"占"前为部分、"每/均"后为份数。
- 🟠 百分点 vs 百分比：百分数是率（%）；百分点是两百分数作差的单位——比重变化量、增速差都用百分点，别写"增长了 X% 个百分点"或把百分点当百分数算。
- 🟠 是几倍 vs 多几倍：是几倍 = A/B（含基数本身）；多几倍 = A/B − 1（超出的部分）。当 A 为现期、B 为基期时，多几倍 = 增长率，是几倍 = 1+增长率。
