## 本章任务
地理知识涵盖自然地理、中国地理、人文地理，占比不大但出题灵活（常配图表/诗词/历史）。重点记我国地形区、气候类型、生态与名胜，以及天体系统与时间的对应。

## 考点框架
- ⭐ 自然地理（中★★★）、中国地理（低★★★）、人文地理（低★★★）
- ⭐ 高频易背：八大行星特征、大气分层与降雨类型、三级阶梯与四大高原/盆地/平原、秦岭-淮河分界线、四大石窟与名山；出题重国情事物、气候类型、生态地理

## 核心判定

**天体系统（太阳 / 八大行星 / 月球）**
| 对象 | 要点 |
| 太阳 | 约3/4氢；太阳黑子、耀斑是活动主要标志；活动周期约11年 |
| 八大行星 | 水金地火木土天海（近→远） |
| 水星 | 离日最近、公转最快、体积质量最小、昼夜温差最大 |
| 金星 | 长庚/启明/太白；自东向西自转，距地最近、最亮、自转最慢 |
| 地球 | 类地行星质量密度最大、唯一生命；自转24h（昼夜）、公转365天（四季）；南极站长城(首)/中山/昆仑/泰山/秦岭，北极黄河站 |
| 木星 | 质量体积最大、自转最快 |
| 土星 | 光环最美 |
| 海王星 | 最远、风速最快、数学预测发现 |
| 月球 | 唯一天然卫星，本身不发光；月相 新月(初一)→上弦(初七/八)→满月(十五/六)→下弦(廿二/三)，日食农历初一、月食十五 |

**大气与气候（分层 / 降雨 / 灾害）**
| 项目 | 要点 |
| 大气成分 | 氮气78%、氧气21% |
| 对流层 | 海拔升1000米温度降约6℃；雨雪云雾等主要天气现象在此 |
| 平流层 | 气流平稳，利于飞机飞行 |
| 暴雨 | 日降雨≥50mm；预警蓝黄橙红，红色最高 |
| 降雨类型 | 对流雨、地形雨、锋面雨、台风雨；梅雨＝锋面雨（6-7月） |
| 气象灾害 | 干旱、洪涝、寒潮、台风 |

🔴 厄尔尼诺（太平洋中东部海水异常变暖）vs 拉尼娜（异常变冷），常交替出现。
🔴 地壳：内圈层地壳/地幔/地核，外圈层大气/生物/水圈。地震纵波先到（先上下颠簸）、横波破坏为主；三大地震带：环太平洋、欧亚、海岭。
🔴 地貌：喀斯特（水溶蚀，桂林/石林/张家界）、雅丹（风蚀，魔鬼城/罗布泊）、丹霞（陡崖红层，武夷山/龙虎山/丹霞山）。

**中国三级阶梯（地形区）**
| 阶梯 | 地形区 |
| 一级 | 青藏高原、柴达木盆地 |
| 二级 | 内蒙古/黄土/云贵高原，塔里木/准噶尔盆地 |
| 三级 | 东北/华北/长江中下游平原，东南丘陵 |
| 分界 | 一二级：昆仑—祁连—横断；二三级：大兴安岭—太行—巫山—雪峰山 |

**四大高原（地位 / 特点）**
| 高原 | 地位 | 特点 |
| 青藏高原 | 世界屋脊、地球第三极 | 雪山冰川、太阳能最丰富 |
| 内蒙古高原 | 中国第二大 | 平坦干燥，草原沙漠广（"瀚海"） |
| 黄土高原 | 世界最大黄土堆积区 | 沟壑纵横、水土流失严重 |
| 云贵高原 | 中国第四大 | 地无三尺平、喀斯特地貌广 |

🔴 四大盆地：塔里木（世界第一大内陆盆地，塔里木河＝中国最长内流河）、准噶尔（中国第二大，"塞北江南"）、柴达木（世界地势最高，"聚宝盆"）、四川（紫色盆地，"天府之国"）。
🔴 三大平原：东北（中国最大）、华北（第二大，长芦盐场最大海盐场）、长江中下游（"鱼米之乡"）。
🔴 河流：长江＝世界第三长河、亚洲第一大河，注入东海；黄河＝亚洲第二长河，注入渤海，下游"悬河"。

**秦岭—淮河分界线（南北对比）**
| 指标 | 北侧 | 南侧 |
| 1月均温 | ＜0℃ | ＞0℃ |
| 年降水量 | ＜800mm | ＞800mm |
| 温度带 | 暖温带 | 亚热带 |
| 耕地/作物 | 旱地、小麦玉米 | 水田、水稻 |
| 植被 | 落叶阔叶林 | 常绿阔叶林 |

🔴 季风区与非季风区分界：大兴安岭—阴山—贺兰山—乌鞘岭—巴颜喀拉山—唐古拉山—冈底斯山，与400mm等降水量线重合；降水东南向西北递减（火烧寮最多、托克逊最少）。
🔴 气候：复杂多样（东部季风/西北温带大陆性/青藏高原山地）+ 季风显著（夏高温多雨、冬寒冷少雨，梅雨、伏旱）。

**人文地理（石窟 / 名山 / 民族）**
| 类别 | 要点 |
| 四大石窟 | 莫高窟、云冈、龙门、麦积山 |
| 四大佛教名山 | 五台(文殊)、普陀(观音)、峨眉(普贤)、九华(地藏) |
| 三山五岳 | 黄山/庐山/雁荡；五岳泰华衡恒嵩，泰山五岳之首 |
| 民族 | 56个；壮族人口最多少数民族，回族分布最广，云南少数民族最多 |

🔴 宗教：佛教、道教、伊斯兰教、天主教、基督教；维吾尔族/回族多伊斯兰，藏族多藏传佛教。

## 解题步骤
- 🟢 自然地理题先定位"现象→成因"：昼夜＝地球自转、四季＝地球公转、天气在对流层、飞行在平流层
- 🟢 中国地理题套"分界线"框架：秦岭-淮河定南北、三级阶梯定地形区、400mm线定季风区
- 🟢 人文题记"之最/首位"：泰山五岳之首、龙门石窟造像最多、壮族少数民族人口最多

## 易混辨析
- 🟠 昼夜更替(地球自转) vs 四季更替(地球公转)：成因不同，常张冠李戴
- 🟠 最长河(长江，世界第三) vs 最长内流河(塔里木河)：别把"内流"漏掉
- 🟠 秦岭-淮河南北：1月均温0℃、年降水800mm、旱地小麦 vs 水田水稻
- 🟠 对流层(天气现象) vs 平流层(利于飞行)：分层用途别混
- 🟠 日食(农历初一) vs 月食(农历十五)：发生时间不同
- 🟠 喀斯特(水蚀) vs 雅丹(风蚀) vs 丹霞(红层)：三类地貌成因与代表
- 🟠 纵波(先到、上下颠簸) vs 横波(造成破坏)：地震破坏主因是横波
- 🟠 金星(距地最近、自东向西自转) vs 水星(离日最近、公转最快)
- 🟠 长江注入东海 vs 黄河注入渤海；厄尔尼诺(变暖) vs 拉尼娜(变冷)

## 错题提醒
- 例题（P139）八大行星：冥王星不在八大行星；水星体积质量最小、火星非距地最近（金星最近）、自转最快是木星
- 例题（P143）四大高原特征：云贵高原多喀斯特、泥石流，非"多火山台风"
- 例题（P145）自然人文展览专题：胡焕庸线对应"东与西"、五岳神圣性均成立，注意专题名称贴切度
- 限时训练（P145-146）1-3：太阳直射点回归运动、名山描述（道教四大名山/雅丹≠武夷山）、人口民族（云南非海南民族最多）
- 首轮重点复核：第一节 自然地理（八大行星特征、大气分层、地貌类型）、第二节 中国地理（三级阶梯与四大高原/盆地特征、秦岭-淮河对比）
