## 核心判定
- 🔴 物质的唯一特性 / 本质属性：客观实在性；物质的根本属性（固有属性）和存在方式：运动（P13、P25）
- 🔴 运动是绝对的、无条件的、永恒的；静止是相对的、有条件的、暂时的；只肯定运动→相对主义诡辩论，只肯定静止→形而上学（P25）
- 🔴 马克思两大发现＝唯物史观、剩余价值学说；辩证法与形而上学的根本对立＝是否承认内部矛盾 / 矛盾（P5、P48）
- 🔴 对立统一规律是辩证法的实质和核心，揭示事物发展的源泉和动力（P61）
- 🔴 质量互变规律揭示形式和状态；否定之否定规律揭示方向和道路；对立统一规律揭示源泉和动力（P58、P60、P61）
- 🔴 承认矛盾普遍性是坚持唯物辩证法的前提；认识矛盾特殊性是正确解决矛盾的前提（关键）；分析矛盾特殊性是正确认识事物的基础；矛盾分析法是人类认识世界和改造世界的根本方法（P66）
- 🔴 生产方式是社会发展的决定力量；物质资料的生产方式是人类社会存在和发展的基础（P16、P130）
- 🔴 生产力是最活跃、最革命的因素，是社会发展的最终决定力量；社会基本矛盾是人类社会发展的根本动力（P130、P131）
- 🔴 生产资料所有制形式是生产关系的基础，是区分社会制度的根本标志；国家政权是上层建筑的核心（P131）
- 🔴 实践是检验真理的唯一标准，是沟通主观与客观的桥梁；实践具有直接现实性（P111）
- 🔴 真理的本质属性是客观性；真理与谬误有明确界限，二者在一定条件下相互转化（P112、P113）
- 🔴 意识的本质：内容是客观的，形式是主观的；劳动在意识产生的过程中起着决定作用，语言是意识的物质外壳，人脑是意识的物质器官（P28）
- 🔴 实践决定认识的四方面：来源、发展动力、目的和归宿、检验真理的唯一标准（P111）
- 🔴 认识过程的两次飞跃：第一次感性认识→理性认识，第二次理性认识→实践；认识过程具有反复性、无限性（P112）
- 🔴 新事物必然战胜旧事物；区分新旧事物的标志是符合事物发展的必然趋势，时间先后和形式新奇与否都不是辨别标准（P54）
- 🔴 实践的特征：客观物质性、自觉能动性、社会历史性、直接现实性（P111）

## 解题步骤
- 🟢 哲学类型判断（唯物 / 唯心）：抓"谁是世界本原 / 老大"——强调"物、气、天（自然规律）"→唯物；强调"心、我、人"→主观唯心；强调"天意老天爷、理、绝对观念、理念"→客观唯心（P20、P21）
- 🟢 "天"字辨析：天行有常 / 制天命而用之＝自然规律（唯物）；生死有命富贵在天 / 道之大原出于天＝天意（客观唯心）（P20）
- 🟢 限定语定位：见"决定 / 根据 / 源泉 / 根本动力 / 实质和核心 / 基础"等词，先对回原理——物质决定意识（P30）、内因是根据（P69）、生产方式是决定力量（P130）、生产力是最终决定力量（P130）
- 🟢 意识 / 实践挖坑：凡"意识决定…""创造规律""意识直接改造世界""整体功能无条件＞部分之和"一律错；只有实践配"直接现实性"（P32、P172、P212）
- 🟢 联系题：见"根据自身需要建立联系""任何事物之间都有联系"均错；应为"根据事物固有联系建立新的具体联系"（P52、P73）
- 🟢 矛盾不平衡性：题干"做事重点 / 关键 / 中心 / 重中之重"→主次矛盾；"性质 / 主流 / 本质 / 怎么看"→主次方面（P68）
- 🟢 内外因：强调"自身 / 自身努力 / 关键"→内因；强调"外部条件 / 国际环境"→外因（P69、P107）
- 🟢 认识论两条路线：辩证唯物主义能动反映论（认识源于实践、主体对客体能动反映）vs 唯心主义先验论；真理是一元的，不是多元的（P197）
- 🟢 "源泉和动力"限定语：只认"矛盾"和"社会基本矛盾"；"同一性是源泉动力""斗争性是源泉动力"均错（P64、P75）
- 🟢 古语 / 成语题：先直译句意再对回原理——"流水不腐"＝运动；"千里之堤溃于蚁穴"＝量变；"团结—批评—团结"＝否定之否定；"仁者心动"＝脱离物质谈运动（唯心）（P92、P25）
- 🟢 漫画题：先看标题与夸张处，再定指向（常考矛盾属性、主次方面转化、联系客观性）（P105、P203）
- 🟢 认识论路线题："从群众中来，到群众中去"的工作方法＝从实践到认识、从认识到实践（P125）
- 🟢 价值观题：价值判断是价值选择的基础，选项把二者说反则错（P235）

## 易混辨析
- 🟠 唯物 vs 唯心：分歧是"思维与存在 / 意识与物质何者为第一性（本原）"。唯物＝物质是本原（古代朴素 / 近代形而上学 / 辩证唯物）；唯心＝意识是本原（主观唯心：人、我、心；客观唯心：老天爷、理、柏拉图理念、黑格尔绝对观念）。可知论 vs 不可知论是另一对分歧（P10、P13）
- 🟠 辩证法 vs 形而上学：根本对立在于"是否承认矛盾（内部矛盾）"。辩证法＝联系、发展、全面、承认矛盾；形而上学＝孤立、静止、片面、否认矛盾（P48）
- 🟠 认识论两条路线：辩证唯物主义能动反映论（认识是主体对客体能动的反映，来源实践）vs 唯心主义先验论（认识先于实践 / 生来就有）；真理一元论（P113、P197）
- 🟠 生产力 vs 生产关系：生产力（人 + 劳动资料 + 劳动对象，实体性要素；劳动资料中的生产工具是生产力发展水平客观标志）表现人与自然关系，最活跃革命、最终决定力量；生产关系（生产资料所有制 + 地位关系 + 产品分配）表现人与人经济关系，生产资料所有制是基础、区分社会制度根本标志。生产力决定生产关系，生产关系反作用（P128、P130、P131、P137）
- 🟠 经济基础 vs 上层建筑：经济基础＝同生产力相适应的生产关系总和，其中生产资料所有制具决定意义；上层建筑＝意识形态（观念上层建筑）+ 政治法律制度设施（政治上层建筑，国家政权是核心）。经济基础决定上层建筑，上层建筑反作用（P128、P131、P139）
- 🟠 真理的绝对性 vs 相对性：绝对性＝真理是对客观事物及其规律的正确反映、人能正确认识无限发展的客观世界（无条件承认）；相对性＝真理的条件性，是对客观对象一定方面 / 层次 / 程度的正确认识（有条件）。二者是同一客观真理的两种属性；真理与谬误有明确界限，在一定条件下相互转化（P112、P113）
- 🟠 矛盾同一性 vs 斗争性：斗争性无条件绝对（相互排斥），同一性有条件相对（相互依赖、贯通）；同一以差别对立为前提，斗争性寓于同一性之中并为其制约。常见错：把"同一性寓于斗争性"说反（P63、P64）
- 🟠 矛盾普遍性 vs 特殊性：普遍性＝处处有矛盾时时有矛盾（方法论一分为二）；特殊性＝具体矛盾及各方面特点（方法论具体问题具体分析）；普遍性寓于特殊性之中并通过特殊性表现，二者相互转化（P65、P66）
- 🟠 量变 vs 质变：量变是同一质态范围内的渐进不显著变化；质变是事物根本性质的变化、由一种质态向另一种质态的飞跃。"量变必然导致质变"错，须"量变达到一定程度必然引起质变"（P57、P89）
- 🟠 整体 vs 部分：整体统率部分、部分影响整体；整体具有部分所没有的新功能。"立足部分"错，应立足整体；整体功能大于部分之和须以有序结构为条件（P52、P73）
- 🟠 "根本方法"限定语：矛盾分析法是人类认识世界和改造世界的根本方法；系统优化方法不是根本方法（P66、P184）
- 🟠 可知论 vs 不可知论：分歧是"思维能否认识存在"；马克思主义哲学坚持可知论，认为思维与存在具有同一性（P10）
