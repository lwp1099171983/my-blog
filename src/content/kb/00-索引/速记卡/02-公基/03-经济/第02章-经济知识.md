## 考点框架
- ⭐ 五节：市场和市场经济 / 微观经济 / 宏观经济 / 国际经济 / 经济学名词
- ⭐ 考查频率（章节导学 P59）：市场和市场经济 ★★★★★、宏观经济 ★★★★★；经济学名词 ★★★★；微观经济 ★★★、国际经济 ★★★
- ⭐ 主线：市场机制（价格/供求/竞争/风险）是政府调控前提；宏观调控靠财政+货币两大手段；指标看 CPI/PPI/基尼/恩格尔

## 核心判定
- 🔴 资源配置两种：计划配置（事前调节）、市场配置（事后调节，实质是价值规律调节）
- 🔴 市场机制四要素：价格机制（最重要）、供求机制、竞争机制、风险机制；风险机制最高层次＝企业破产
- 🔴 市场配置三缺陷：自发性、盲目性、滞后性
- 🔴 市场失灵四因素：垄断、外部性（正/负）、公共物品（非竞争+非排他）、信息不对称
- 🔴 社会主义市场经济：市场对资源配置起决定性作用；宏观调控与市场机制内在统一
- 🔴 分配制度：按劳分配为主体、多种分配方式并存；按生产要素分配（劳动/资本/管理知识产权）
- 🔴 三次分配：初次分配注重效率（市场形成）/ 再分配侧重公平（税收、转移支付、社保）/ 第三次分配（道德、捐赠）
- 🔴 需求法则：价格↑需求↓，反向变动；需求弹性——必需品/缺替代→缺乏弹性（丰收悖论：农产品必需，大丰收价跌收入反减），奢侈品/有替代→富有弹性
- 🔴 互补品价↑→本商品需求↓；替代品价↑→本商品需求↑
- 🔴 供求法则：供给>需求→价跌；供给<需求→价涨
- 🔴 社会再生产四环节：生产（决定性、首要）—分配—交换—消费（最终目的和动力）
- 🔴 宏观调控四目标：促进经济增长（最主要）、增加就业、稳定物价、保持国际收支平衡
- 🔴 GDP：一国/地区一定时期运用生产要素生产的全部最终产品市场价值；失业常通过失业率反映
- 🔴 通胀：货币供给>实际需求（购买力>产出），实质是社会总需求>总供给，物价持续普遍上涨
- 🔴 CPI＝居民生活相关产品及劳务价格变动指标（观察通胀）；PPI＝原材料和中间投入品价格指数
- 🔴 国际收支平衡：净出口(出口-进口) − 净资本流出(本国居民购外国资产 − 外国人购本国资产) = 0
- 🔴 财政收入四部分：税（强制、无偿、固定三特征，最主要）、利、债（公债/国债，到期还本付息）、费
- 🔴 财政支出两类：政府购买（实质支出，直接形成需求）、政府转移支付（货币性支出，无实物交换）
- 🔴 货币政策工具：法定存款准备金率、再贴现率、公开市场业务（央行买卖证券吞吐基础货币、非盈利）、基准利率
- 🔴 贸易顺差＝出超（出口>进口）；逆差＝入超/赤字（出口<进口）
- 🔴 汇率：本币升值→出口减、进口增、出境旅游增、资本流入；本币贬值→出口增、进口减
- 🔴 汇率制度：固定汇率（政府制定）/ 浮动汇率（市场供求）；我国实行有管理的浮动汇率
- 🔴 标价法：直接标价法（一定单位外币折本币）、间接标价法（一定单位本币折外币）
- 🔴 三大支柱：IMF（监察汇率，1945 华盛顿）、WB 世界银行（低息贷款助脱贫，成员须为 IMF 成员）、WTO（日内瓦，2001.12.11 中国加入）
- 🔴 GNI＝GNP（国民总收入）；基尼系数 0（平等）~1（不平等），0.4 为警戒线；恩格尔系数＝食品支出/消费支出（生活水平）
- 🔴 机会成本（放弃的其他最大收益，"鱼与熊掌"）vs 沉没成本（已发生不可改变，"覆水难收"）
- 🔴 边际效用递减（消费量↑每单位效用增量递减）；三驾马车＝投资、消费、出口
- 🔴 三大产业：一产农业、二产工业和建筑业、三产流通+服务；灰犀牛（大概率大影响）vs 黑天鹅（极罕见）
- 🟢 工具速判：见"税收/国债/政府购买/转移支付"→财政政策；见"准备金率/再贴现/公开市场/利率/基准利率"→货币政策

## 解题步骤
1. 🟢 判手段：含税收、国债、政府购买、转移支付→财政政策；含法定存款准备金率、再贴现率、公开市场业务、利率→货币政策
2. 🟢 判方向：经济过热/通胀→紧缩（增税减支）；经济萧条/失业→扩张（减税增支）
3. 🟢 算 GDP：只计当期最终产品；二手交易（旧房/旧车中介费）、金融中介费不计入
4. 🟢 判汇率影响：本币升值→出口减进口增；结合贸易顺差/逆差看国际收支

## 易混辨析
- 🟠 计划配置 vs 市场配置：计划是事前调节，市场是事后调节（价值规律调节）
- 🟠 互补品 vs 替代品：价变对本商品需求方向相反，做题先判二者关系再套"价↑需求↓"
- 🟠 扩张性 vs 紧缩性（财政/货币同向）：过热→紧缩（提率提税减支），萧条→扩张（降率减税增支）
- 🟠 初次/再/第三次分配：效率—公平—道德三条线，再分配靠税收与社保
- 🟠 固定汇率 vs 浮动汇率：政府制定 vs 市场供求；我国有管理的浮动
- 🟠 直接标价 vs 间接标价：外币折本币 vs 本币折外币

| 概念 | 口径 | 常见问法 |
| --- | --- | --- |
| CPI | 居民生活相关产品及劳务价格 | 观察通货膨胀水平 |
| PPI | 原材料、中间投入品价格（成本端） | 工业品成本端价格变动 |
| 财政政策 | 政府（税收、国债、政府购买、转移支付） | "税收/国债"属哪类手段 |
| 货币政策 | 央行（准备金率、再贴现、公开市场、利率） | "降准/公开市场"属哪类手段 |
