## 本章任务
- 公文重识记：概述记基本点；15 种法定公文用"关键词法"对每个文种抓关键词判断；公文规范与处理工作用理解+表格/画图法识记。
- 重点拿下：法定公文适用范围（★★★★★）、公文规范（★★★★）、公文处理工作（★★★）。

## 考点框架
- ⭐ 四大块：公文概述 / 法定公文适用范围（15 文种）/ 公文规范（行文规则+格式要素+语言）/ 公文处理工作（拟制+办理+管理）
- ⭐ 公文概念：党政机关实施领导、履行职能、处理公务的具有特定效力和规范体式的文书；作者为法定作者（依法成立并能以自己名义行使职权、承担义务的组织及其法定代表人）
- ⭐ 分类：按行文方向分上行文/下行文/平行文；按密级分秘密/机密/绝密；按时限分平件/加急件/特急件；按来源分收文/发文
- ⭐ 15 文种：决议、决定、命令、公报、公告、通告、意见、通知、通报、报告、请示、批复、议案、函、纪要
- ⭐ 格式要素分版头、主体、版记三部分（《党政机关公文格式》）

## 核心判定
- 🔴 15 文种适用范围与行文方向（P126）：

| 文种 | 适用范围 | 行文方向 |
|------|----------|----------|
| 决议 | 会议讨论通过的重大决策事项 | 下行 |
| 决定 | 对重要事项决策部署、奖惩有关单位人员、变更撤销下级不适当决定 | 下行 |
| 命令 | 公布行政法规规章、宣布重大强制措施、批准授予晋升衔级、嘉奖 | 下行 |
| 公报 | 公布重要决定或重大事项 | 下行 |
| 公告 | 向国内外宣布重要事项或法定事项 | 下行 |
| 通告 | 在一定范围内公布应遵守或周知事项 | 下行 |
| 意见 | 对重要问题提出见解和处理办法 | 可上/下/平行 |
| 通知 | 发布传达要求下级执行、批转转发公文 | 下行（主） |
| 通报 | 表彰先进、批评错误、传达精神、告知重要情况 | 下行 |
| 报告 | 向上级汇报工作、反映情况、回复询问 | 上行 |
| 请示 | 向上级请求指示、批准 | 上行 |
| 批复 | 答复下级机关请示事项 | 下行 |
| 议案 | 政府向同级人大/人大常委会提请审议 | 平行 |
| 函 | 不相隶属机关间商洽、询问答复、请批审批 | 平行 |
| 纪要 | 记载会议主要情况和议定事项 | 多向 |

- 🔴 版头要素（6）：份号（涉密标，6位3号阿拉伯数字）、密级和保密期限（绝密/机密/秘密）、紧急程度（特急/加急）、发文机关标志、发文字号（代字+年份+序号，如国发〔2012〕12号）、签发人（上行文须标）
- 🔴 主体要素（9）：标题（机关+事由+文种）、主送机关、正文（首页须显示，结构层次"一、""（一）""1.""（1）"）、附件说明、发文机关署名、成文日期（阿拉伯数字标全、不编虚位）、印章、附注、附件
- 🔴 版记要素（2）：抄送机关、印发机关和印发日期
- 🔴 行文一般规则：行文关系按隶属关系和职权范围确定；一般不得越级行文，特殊情况越级须抄送被越过机关
- 🔴 上行文规则：主送一个上级、不得抄送下级；请示一文一事；不得在报告等非请示公文中夹带请示事项；除直接交办外不得以机关名义向负责人报送
- 🔴 公文办理：发文复核→登记→印制→核发；收文签收→登记→初审→承办→传阅→催办→答复
- 🔴 公文拟制：起草→审核（办公厅/室）→签发（重要公文和上行文由主要负责人签发）
- 🔴 语言特点：准确、庄重、平实、简明；表达方式叙述、议论、说明；第一要求是准确

## 解题步骤
1. **文种判断题**：抓关键词——"向上级请求/批准"→请示；"答复下级"→批复；"不相隶属商洽请批"→函；"公布周知社会"→通告/公告；"奖惩/变更撤销"→决定
2. **格式要素题**：先判版头/主体/版记归属，再抓特殊规则（份号仅涉密标、上行文必标签发人、成文日期阿拉伯数字不编虚位、有署名应加盖印章）
3. **行文规则题**：上行文查"主送一个上级+一文一事+不夹带请示"；越级查"抄送被越过机关"
4. **办理流程题**：发文四步、收文七步按顺序记；联合办理公文原件由主办机关归档

## 易混辨析
- 🟠 请示 vs 报告：请示向上级请求指示批准、一文一事、事前行文、不批复不行；报告汇报工作反映情况回复询问、不需批复。报告等非请示公文不得夹带请示事项
- 🟠 通知 vs 通报 vs 通告：通知（下行，要求下级执行/批转转发，号称"公文之王"）；通报（下行，表彰批评传达精神告知情况，重教育）；通告（一定范围内公布应遵守周知，告社会群众）。通知重"执行"、通报重"引导"、通告重"遵守"
- 🟠 函 vs 意见：函用于不相隶属机关之间商洽询问请批（平行）；意见用于对重要问题提见解处理办法（可上可下可平行，行文灵活）
- 🟠 公告 vs 通告：公告向国内外告知、范围大；通告在一定范围内告知、范围小
- 🟠 命令易错：撤销下级不适当"决定"用决定而非命令；命令由特定机关使用，财政局等不能随意用命令行文
