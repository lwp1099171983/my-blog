## 核心判定
- 🔴 正式渊源制定主体（重点背）：（P7-8）

| 形式 | 制定主体 |
| --- | --- |
| 宪法 | 修改：全国人大；解释：全国人大常委会；监督实施：全国人大及其常委会。制宪主体—人民；制宪机关—第一届全国人大第一次全体会议 |
| 法律（狭义） | 全国人大：基本法律；全国人常：非基本法律 |
| 行政法规 | 国务院 |
| 地方性法规 | 省/自治区/直辖市人大及其常委会；设区的市、自治州人大及其常委会，报省级人常批准后生效 |
| 自治法规 | 自治区人大报全国人常批准；自治州、自治县人大报省/自治区/直辖市人常批准 |
| 规章 | 部门规章：国务院各部委行署和有权直属机构；地方政府规章：省级和设区的市、自治州人民政府 |
| 其他 | 国际条约惯例；经济特区省/市人大及其常委会经济法规；特别行政区法律向全国人常备案；中央军委军事法规；国家监委监察法规 |

- 🔴 法的效力原则：上位法优于下位法（宪法至上、法律高于行政法规、行政法规高于规章、行政法规高于地方性法规）。（P8）
- 🔴 同一位阶冲突：特别法优于一般法、新法优于旧法；法律之间不一致由全国人大常委会裁决，行政法规之间由国务院裁决。（P8）
- 🔴 位阶交叉：地方性法规与部门规章不一致的，由国务院提出意见，认为应适用地方性法规的决定适用，认为应适用部门规章的提请全国人大常委会裁决；部门规章之间或部门规章与地方政府规章之间不一致的，由国务院裁决。（P8）
- 🔴 法律规则（按内容）：授权性规则=可为（可以）；义务性规则=命令性（应当、必须）+禁止性（禁止、不得）。（P11）
- 🔴 法律规则（确定性）：确定性规则直接适用；委任性规则须机关定细则；准用性规则须援引其他规定。（P11）
- 🔴 法律原则适用条件：穷尽法律规则，方得适用法律原则；为实现个案正义可优先适用原则，须给强有力理由。（P11）
- 🔴 法律关系三要素：主体、内容（权利义务）、客体（物、人身利益、精神产品、行为结果）。（P12）
- 🔴 法律关系主体三类：公民（自然人）、机构和组织（法人）、国家。（P12）
- 🔴 法律事实：法律关系产生/变更/消灭须有法律规范＋法律事实；分法律事件（不以意志为转移：社会事件如革命战争暴乱罢工、自然事件如灾害出生死亡）与法律行为（以意志为转移：合法/违法，如合同遗嘱）。（P12）
- 🔴 法律责任四类：刑事、民事、行政、违宪；免责：时效、不诉、协议、自首立功、人道。（P13）
- 🔴 法的运行各环节主体：立法=一定国家机关；执法=国家行政机关及其工作人员；司法=人民法院和人民检察院（被动性）；守法=一切国家机关、社会组织和公民个人。（P13-14）
- 🔴 法律解释主体：立法解释=全国人大常委会（宪法法律）/省级人大常委会（地方性法规）；司法解释=最高法、最高检；行政解释=国务院及其部门。（P14）

## 解题步骤
- 🟢 渊源判定题：先判文件性质（宪法/法律/行政法规/地方性法规/规章/自治法规），再对应制定主体；地方规章与部门规章制定主体不同要分清。
- 🟢 效力冲突题：先定位"位阶"—上下位用上位法优先；同位阶用特别/新法；交叉的授权（国务院/全国人常）别记反。
- 🟢 法律事实题：先问"是否以人的意志为转移"—否=事件（自然/社会），是=行为（合法/违法）。

## 易混辨析
- 🟠 法律 vs 行政法规制定主体：法律=全国人大及全国人常，行政法规=国务院，别混。
- 🟠 地方性法规"批准"：设区的市/自治州制定须报省级人常批准；自治区自治法规报全国人常批准，层级不同。
- 🟠 部门规章 vs 地方政府规章：前者国务院部委，后者省级/设区的市政府，制定主体不同。
- 🟠 授权性（可以）vs 义务性（应当/必须/禁止/不得）：模式词是判定关键，别把"可以"当义务。
- 🟠 法律事件 vs 法律行为：事件不以意志为转移（出生死亡、战争灾害），行为以意志为转移（合同遗嘱）；"死亡"是事件非行为。
- 🟠 执法（主动性、单方面）vs 司法（被动性、严格程序）：主体也不同（行政 vs 法检）。
- 🟠 立法解释主体双重：宪法法律归全国人常，地方性法规归省级人常。
