> 来源：公基讲义·法律 P59-89（上岸鸭）。生成日期 2026-09-24。配套章节：`02-公基/02-法律/第05章-民法.md`。

## 本章任务
- 掌握民法十一大制度模块；重点背记行为能力年龄线、宣告失踪/死亡期限、诉讼时效期间与中止中断、物权变动公式、各类撤销权期间、婚姻无效与可撤销、继承顺序与遗嘱形式、侵权责任归责原则，做到"要件＋数字＋结论"三对应。

## 考点框架
- ⭐ 十一大节：一民法概述／二民事主体／三民事法律行为／四代理／五诉讼时效／六物权／七合同／八人身权／九婚姻家庭／十继承／十一侵权责任（高频★：民事主体、民事法律行为、物权、婚姻家庭、继承、侵权责任）
- ⭐ 民法调整对象：平等主体的自然人、法人和非法人组织之间的人身关系和财产关系；《民法典》是第一部以"典"命名的法律（基础性、私法基本法、社会生活的百科全书）；基本原则含民事权益受保护、平等、自愿、公平、诚实信用（"帝王条款"）、合法和公序良俗、绿色、禁止权利滥用

## 核心判定
【二、民事主体】
- 🔴 民事权利能力：从出生到死亡；胎儿涉及遗产继承、接受赠与等视为有，娩出死体则自始不存在（P60）
- 🔴 行为能力年龄/精神线（P60）：

| 类型 | 要件 | 实施行为规则 |
|---|---|---|
| 完全 | 成年人；16周岁以上以自己劳动收入为主要生活来源视为完全 | 独立实施 |
| 限制 | 8周岁以上未成年人；不能完全辨认自己行为的成年人 | 纯获利益或相适应有效，其余需法定代理人代理/同意追认 |
| 无 | 不满8周岁；不能辨认自己行为者 | 由法定代理人代理 |

- 🔴 监护顺序（P60-61）：未成年人→①父母②祖父母外祖父母③兄姐④其他愿任者（经同意）；无/限成年人→①配偶②父母子女③其他近亲属④其他愿任者（经同意）；父母可通过遗嘱指定监护人
- 🔴 宣告失踪/死亡（P61）：

| 情形 | 期限 | 法律后果 |
|---|---|---|
| 宣告失踪 | 下落不明满2年 | 财产由配偶、成年子女、父母等代管 |
| 宣告死亡 | 下落不明满4年；意外事件满2年；意外证明不可能生存不受2年限制 | 婚姻关系自死亡宣告日起消除，撤销后自行恢复（配偶再婚或书面声明不愿恢复除外）；子女被收养不得主张无效；撤销后有权请求返还财产 |

- 🔴 法人：权利能力与行为能力从成立到终止，以全部财产独立承担民事责任；非法人组织含个人独资企业、合伙企业、不具有法人资格的专业服务机构

【三、民事法律行为】
- 🔴 有效三要件（P63）：①行为人有相应民事行为能力②意思表示真实③不违反法律行政法规强制性规定、不违背公序良俗
- 🔴 效力待定（P63）：限制行为能力人超范围行为经追认有效；无权代理未经追认对被代理人不生效；相对人可催告自收到通知之日起30日内追认，未作表示视为拒绝，追认前善意相对人有撤销权（通知方式）
- 🔴 可撤销期间（P63）：

| 类型 | 撤销权人 | 撤销权期间 |
|---|---|---|
| 重大误解 | 行为人（法院/仲裁机构） | 知道或应知撤销事由起90日内；行为发生起5年内 |
| 欺诈 | 受欺诈方 | 知道或应知撤销事由起1年内 |
| 胁迫 | 受胁迫方 | 胁迫行为终止起1年内 |
| 显失公平 | 受损害方 | 知道或应知撤销事由起1年内 |
| 通用 | — | 知道撤销事由后明示或以行为放弃则消灭 |

- 🔴 无效五情形（P64）：①无行为能力人实施②虚假意思表示③违反法律法规强制性规定（该规定不导致无效除外）④违背公序良俗⑤恶意串通损害他人；无效/被撤销的自始无法律约束力

【四、代理】
- 🔴 代理：代理人在权限内以被代理人名义与第三人为民事行为，对被代理人直接生效；应本人亲自实施的不得代理（P64）
- 🔴 滥用：自己代理、双方代理（经同意/追认除外）；代理人与第三人恶意串通→无效，代理人+相对人连带责任（P65）
- 🔴 狭义无权代理 vs 表见代理：表见代理虽未经追认，因本人过失/特殊关系致善意第三人确信有代理权，法律效果直接归本人承受（P65）

【五、诉讼时效】
- 🔴 期间（P65-66）：

| 类型 | 期间 | 起算 |
|---|---|---|
| 普通诉讼时效 | 3年 | 知道或应知权利受损及义务人之日起 |
| 最长时效 | 20年 | 权利受损之日起；特殊情况可延长 |

- 🔴 特殊起算：分期履行自最后一期届满；无/限行为能力人对法定代理人请求权自法定代理终止；未成年人遭性侵自年满18周岁起算
- 🔴 中止：最后6个月内因障碍不能行使请求权→中止，原因消除之日起满6个月时效届满（P66）
- 🔴 中断：提出履行请求/同意履行/诉讼或仲裁等→从中断、程序终结起重新计算（P66）
- 🔴 不适用诉讼时效（P67）：停止侵害、排除妨碍、消除危险；不动产物权和登记的动产物权返还财产；支付抚养费/赡养费/扶养费；其他

【六、物权】
- 🔴 物权变动公式（P67-68）：不动产物权＝法律行为有效＋处分权＋登记；动产物权＝法律行为有效＋处分权＋交付/放弃占有
- 🔴 区分原则：合同自成立时生效，未登记不影响合同效力；预告登记后未经同意处分不发生物权效力，债权消灭或自能登记起90日内未申请则失效（P67）
- 🔴 善意取得：善意、对价受让且占有→取得所有权；遗失物、盗赃物、埋藏物不适用；拾得遗失物发布招领公告起1年内无人认领归国家（P69）
- 🔴 居住权（P69-70）：书面合同或遗嘱；无偿设立；自登记时设立；不得转让、继承；住宅不得出租（另有约定除外）
- 🔴 担保物权（P70-72）：抵押权（不转移占有，不动产自登记设立、动产自合同生效设立）、质权（动产/权利出质，自交付/登记设立，流质无效）、留置权（合法占有，同一法律关系，企业间除外）；担保合同是从合同，主合同无效则担保无效
- 🔴 担保竞合（P72）：抵押权与质权按登记/交付时间先后；与留置权竞合留置权人优先受偿；超级动产抵押权（交付后10日内登记）优先（留置权人除外）

【七、合同】
- 🔴 要约 vs 要约邀请（P73）：拍卖/招标/招股/债券募集/基金招募/商业广告宣传/寄送价目表为要约邀请；商业广告内容符合要约条件构成要约
- 🔴 赠与撤销（P73）：任意撤销（权利转移前可撤，公证或公益道德义务不得任意撤销）；法定撤销（严重侵害/扶养义务不履行/约定义务不履行）
- 🔴 租赁（P73-74）：不得超20年，超期部分无效；6个月以上应书面，未书面且无法确定期限视为不定期；视为同意转租（知道或应知6个月内未异议）；买卖不破租赁；优先购买权15日内未明示购买视为放弃（按份共有人/近亲属除外）

【八、人身权】
- 🔴 人格权（P75-77）：生命权、身体权、健康权、姓名权、名称权、肖像权、名誉权、荣誉权、隐私权等
- 🔴 身份权（P77）：配偶权、亲权、亲属权；仅存在于自然人之间，不得抛弃和转让

【九、婚姻家庭】
- 🔴 结婚实质要件（P77-78）：①双方完全自愿②男不早于22周岁、女不早于20周岁③直系血亲或三代以内旁系血亲禁止④一夫一妻；完成结婚登记确立婚姻关系
- 🔴 无效婚姻三事由（P78）：重婚；禁止结婚的亲属关系；未到法定婚龄→自始无约束力，无过错方有权请求损害赔偿
- 🔴 可撤销婚姻（P78-79）：胁迫（自胁迫终止起1年内；被限自由自恢复自由起1年内）；重大疾病未如实告知（自知道或应知撤销事由起1年内）→自始无约束力，无过错方有权请求损害赔偿
- 🔴 夫妻财产（P78-79）：共同＝工资奖金劳务报酬、生产经营投资收益、知识产权收益、继承/受赠财产（确定只归一方除外）等；个人＝婚前财产、人身损害赔偿、遗嘱/赠与确定只归一方、专用生活用品等
- 🔴 离婚（P79-80）：冷静期30日（收到申请起30日内可撤回）；离婚限制（女方怀孕/分娩后1年内/终止妊娠后6个月内男方不得提，女方提或法院认为必要除外）；抚养（不满2周岁以母亲为原则，已满8周岁尊重真实意愿）；损害赔偿＝重婚/同居/家暴/虐待遗弃/其他重大过错

【十、继承】
- 🔴 法定继承顺序（P81-82）：

| 顺序 | 继承人 | 份额 |
|---|---|---|
| 第一 | 配偶、子女、父母（丧偶儿媳对公婆/丧偶女婿对岳父母尽主要赡养义务者同列） | 一般均等 |
| 第二 | 兄弟姐妹、祖父母、外祖父母 | 无第一顺序时才由第二顺序继承 |

- 🔴 遗嘱形式（P81-82）：自书（亲笔签名注年月日）、代书/打印/录音录像（两以上见证人）、口头（危急情况，能立书面则无效）、公证；见证人排除无/限行为能力人、继承人、受遗赠人及利害关系人；数份抵触以最后的为准
- 🔴 遗赠与遗赠扶养协议（P82-83）：受遗赠人知道受遗赠后60日内表示，到期未表示视为放弃；遗赠扶养协议效力优先于遗嘱继承、遗赠和法定继承
- 🔴 代位 vs 转继承（P82-83）：代位是被继承人子女/兄弟姐妹先死，其直系晚辈血亲/子女代位（限继承被代位份额）；转继承是继承开始后、遗产分割前继承人死亡未放弃，转给其继承人

【十一、侵权责任】
- 🔴 归责原则（P84-85）：

| 原则 | 要件 | 适用 |
|---|---|---|
| 过错责任 | 加害行为＋损害＋因果＋过错 | 一般侵权 |
| 过错推定 | 加害行为＋损害＋因果＋推定过错 | 特殊侵权（无行为能力在校受损、物件脱落等） |
| 无过错责任 | 加害行为＋损害＋因果 | 监护人/用人者/产品/动物/高危等 |
| 公平责任 | 双方均无过错 | 紧急避险/见义勇为/高空抛物等分担损失 |

- 🔴 具体侵权要点（P86-89）：监护人责任（尽职责可减轻）、用人者责任（追偿故意/重大过失）、网络侵权（未及时采取措施对扩大部分连带）、产品责任（可向生产者或销售者请求）、机动车（之间过错，与非机动车/行人无过错）、饲养动物（一般无过错，动物园过错推定）、物件损害（脱落坠落过错推定、倒塌连带责任、高空抛物可能加害使用人补偿）

## 解题步骤
1. 🟢 定性：先判断是否为民事法律关系（平等主体人身/财产关系），排除非民法调整
2. 🟢 定主体：核实用行为人年龄/精神状态→行为能力等级，决定行为是否有效、由谁担责
3. 🟢 定效力：审查法律行为属有效／效力待定／可撤销／无效哪一类，套对应要件
4. 🟢 定权利变动：物权看"登记/交付"公式与善意取得；债权看合同成立与履行
5. 🟢 定时效/期间：识别适用诉讼时效（可中止中断）还是撤销权/追认等不变期间
6. 🟢 定责任：侵权按归责原则（过错/过错推定/无过错/公平）匹配要件，确定责任主体与形态

## 易混辨析
- 🟠 诉讼时效 vs 撤销权期间（除斥性质）：诉讼时效普通3年、最长20年，可中止/中断/延长；撤销权期间（90日/1年/5年）为不变期间，届满或放弃则权利消灭。注：讲义以"撤销权期间"表述，未单列"除斥期间"名词
- 🟠 无效 vs 可撤销 vs 效力待定：无效（5情形）自始无效无需行使；可撤销需撤销权人行使（重大误解/欺诈/胁迫/显失公平），被撤销后自始无效；效力待定须经追认（限制行为能力超范围、无权代理）
- 🟠 物权 vs 债权：物权直接支配排他（所有权/用益/担保）；债权是请求权，合同等产生，无排他性
- 🟠 法定继承 vs 遗嘱继承 vs 遗赠扶养协议：法定按顺位份额均等；遗嘱按被继承人意思，数份抵触以最后为准；遗赠扶养协议效力最优先
- 🟠 善意取得 vs 拾得遗失物：善意取得需善意+对价+占有；遗失物、盗赃物、埋藏物不适用善意取得，遗失物公告1年无人认领归国家
- 🟠 过错责任 vs 过错推定 vs 无过错：一般侵权需证明过错；过错推定（如物件脱落、动物园）由加害人证无错；无过错（如产品、动物、高危）不问过错
- 🟠 代位继承 vs 转继承：代位是被继承人子女先死由其晚辈血亲代位；转继承是继承人后于被继承人死亡、于分割前未放弃，转给其继承人
