# 职测必背清单

> **用途**：刷题前照着背。只列**真正需要背下来**的内容。
> **来源**：`考点速览.md` + 各章讲义原文（上岸鸭讲义）。
> **用法**：刷题前过一遍 → 关书默写 → 写不出来的回讲义查 → 再开刷。
> ⚠️ 标注「待回讲义核对」的条目，速览中只有公式名、未列具体式，使用时请回对应章节原文确认，**不要凭记忆套用**。

## 一、先明确：职测只有三块需要背

| 模块 | 要不要背 | 原因 |
|---|---|---|
| 🔴 判断推理 · 形式逻辑 | **必须背** | 规则型，背不下来直接做错 |
| 🔴 数量关系 · 题型公式 | **必须背** | 不背等于没学 |
| 🔴 资料分析 · 列式公式 | **必须背** | 列不出式就没法算 |
| 🔵 言语理解 | **不用背** | 靠做题校准语感 |

## 二、判断推理 · 形式逻辑（🔴 必须背）

### 1. 假言命题 ⭐最高频 ★★★★★

**翻译规则**
- 充分条件 → 必要条件
- 充分在前 = 前→后：**如果…那么 / 只要…就**
- 必要在前 = 后→前：**只有…才**

**推理规则**
- 肯前必肯后 ✅
- 否后必否前 ✅
- 否前 / 肯后 → **推不出必然结论** ❌
- 逆否等价

**矛盾** = p 且 非q ｜ **真假话**用矛盾法「一找二绕三回」

### 2. 直言命题 ★★★

- **六类型**：所有 / 有些 / 某个 × 是 / 非
- **矛盾三对**：
  - 所有A是B ↔ 有些A非B
  - 所有A非B ↔ 有些A是B
  - 某个A是B ↔ 某个A非B
- **矛盾法**：一找二绕三回
- **推出关系**（知真求真）：所有A是B → 某个A是B → 有些A是B（"所有非"同理）
- **反对关系**：
  - 上反对：所有是 ↔ 所有非（**至少一假**）
  - 下反对：有些是 ↔ 有些非（**至少一真**）
- **三段论**：四种标准形式 + 文氏图；前提型用排除法、结论型用画图法

### 3. 联言 / 选言命题 ★★★

| 类型 | 真假 | 矛盾 |
|---|---|---|
| 联言 p且q | 一假则假、全真则真 | 非p或非q |
| 相容选言 p或q | 一真则真、全假则假 | 非p且非q |
| 不相容选言 要么p要么q | 有且只有一种情况为真（同真同假均为假） | —— |

### 4. 论证题：标志词 + 三角度

**找结论标志词**（背下来，做题时扫）
因此 / 所以 / 认为 / 相信 / 宣称 / 说明 / 表明 / 意味着 / 预测 / 推测 / 由此可知 / 据此推出 / 得出结论

**三要素**：结论、论据、论证联系

**削弱三角度**
1. 削弱结论（直接否定；**只有结论型仅此路**）
2. 削弱论证联系（切断论据与结论的联系；**论据与结论概念或对象不一致时优先**）
3. 削弱论据（论据为某人/机构观点、调查结果、实验发现时）

**加强三角度**
1. 加强结论（解释结论 / 举例）
2. 加强论证联系（**概念或话题不一致时优先**，建立联系）
3. 加强论据

**前提型两法**
- 搭桥法：找论据与结论的不同概念 → 建立联系
- 反向验证法：否定选项代入，结论不成立者为必需前提

**力度比较**（两选项都能削弱/加强时）
本质 > 现象 ｜ 必然 > 可能 ｜ 量大 > 量小 ｜ 直接 > 间接 ｜ 综合 > 单一

### 5. 朴素逻辑 ★★★★★

- **突破口**：确定条件（能得出确定信息）、关联条件（出现次数多的元素）
- **方法**：代入排除法、假设法、图表法（列表 / 画图）

> 🔵 朴素逻辑不用背，靠做题练手感；但"先找突破口"这个意识必须有。

## 三、数量关系 · 公式（🔴 必须背）

### 常用方法（第13章）

**整除判定**（所求为整数；出现除、整除、每、平均、分组）
- 2 / 5 → 看末一位
- 4 / 25 → 看末两位
- 8 / 125 → 看末三位
- 3 / 9 → 看各位和
- 11 → 看奇偶位和之差

**方程法四步**：找等量关系 → 设未知数 → 列方程 → 解方程
- 设小不设大
- 不定方程结合：代入排除、奇偶、整除、尾数；任意范围可用赋 0 法

**比例法**：化简（"分母是自己的，分子是别人的"）→ 统一（找不变量、统一份数、同比变化）→ 计算

**赋值法**适用条件：数据均为比例 / 分数 / 倍数 / 百分数；或 `C=A×B` 且仅一个实际量已知

**十字交叉法**：先确认分子能相加、分母能相加；部分比例分母之比 = 交叉作差之比，作差取大减小

### 九大题型公式（第14章）

**等差数列**
- `a_n = a_1 + (n-1)d`
- `a_n - a_m = (n-m)d`
- 奇数项和 = 中间项 × 项数
- 偶数项和 = 中间两项和 × 项数 ÷ 2

**经济利润**
- `利润 = 售价 - 成本 = 成本 × 利润率`
- `成本 = 售价 ÷ (1 + 利润率)`
- 分段计费按各段分别计算

**工程**
- `W = P × T`
- 给定时间型 → 总量赋最小公倍数
- 效率制约型 → 按效率比赋值
- 效率相同型 → 效率赋 1
- 交替工程 → 按周期处理余量

**行程**
- `S = V × T`
- 相遇：路程和 = 速度和 × 时间
- 追及：路程差 = 速度差 × 时间
- 牛吃草：`Y = (N - X) × T`

**排列组合**
- 分类相加、分步相乘
- 排列有顺序、组合无顺序
- 技巧：枚举、优限、捆绑、插空

**古典概率**
- `P(A) = 事件A样本数 ÷ 总样本数`
- 独立事件：分类相加、分步相乘；计数常结合排列组合

**几何**
- 平面：三角形、菱形、梯形、圆、扇形
- 立体：正方体、长方体、圆柱、圆锥、球
- 勾股定理与特殊直角三角形
- ⚠️ 具体面积 / 体积公式待回第14章讲义核对

**最值**
- 和定最值：目标最大则其他尽量小；目标最小则其他尽量大
- 保证数 = 最不利数 + 1

**容斥**
- 二者：`I = A + B - A∩B + M`
- 三者：标准公式 / 非标准公式
- 交集最小：二者 `A + B - I`；三者 `A + B + C - 2I`
- 必要时画文氏图

### 数字推理（第15章，如考）

- **差数列**：一级差、多级差、构造网络
- **和数列**：相邻两项/三项递推，作和找基础数列
- **倍数数列**：逐商、倍数递推、修正递推
- **特殊形式**：分数、分组、次方、根式、图形、小数 → 分子分母拆分、奇偶分组

## 四、资料分析 · 公式（🔴 必须背）

| 考点 | 公式 / 要点 |
|---|---|
| **一般增长** | `增长量 = 现期值 - 基期值`；`增长率 = 增长量 ÷ 基期值`；现期值 / 基期值 / 增长量 / 增长率**四量互推**；注意同比与环比 |
| **间隔增长** | 间隔增长率公式、间隔基期值公式 ⚠️ 待回第16章核对 |
| **年均增长** | 年均增长率、年均增长量公式 ⚠️ 待回第16章核对 |
| **混合增长** | 根据各部分的基期量、增长量或增长率选择混合增长方法 |
| **比重** | `比重 = 部分 ÷ 总体`；区分现期比重、基期比重、比重变化 |
| **平均数** | `平均数 = 总量 ÷ 份数`；区分现期平均数、基期平均数、平均数变化 |
| **倍数** | `倍数 = A ÷ B`；基期倍数按对应基期量计算 |

## 五、资料分析 · 速算技巧（🟢 要练，理解适用条件）

| 技巧 | 适用条件 | 要点 |
|---|---|---|
| **尾数法** | 简单加减，选项末一位/末几位不同 | 优先看末三位以内；不够减要借位，小数位不足补 0 |
| **特殊数字法** | 分数、百分数，或有熟悉数值的乘除式 | 识别常见分数对应百分数，结合放缩判断 |
| **有效数字法** | 乘除计算、数据大且选项有差距 | 按选项差距确定保留位数，再取近似值 |
| **比较大小** | 多个数或增长量的排序 | 观察比较法、同位比较法、增长量大小比较 |

> 🔵 核心思想：**列式越复杂，选项差距越大，快速估算即可。**

## 六、每日 5 分钟关书默写（自测清单）

- [ ] 假言命题：充分在前怎么翻？必要在前怎么翻？
- [ ] 假言命题：哪两个方向能推出？哪两个推不出？
- [ ] 直言命题矛盾三对
- [ ] 直言命题推出链（所有 → 某个 → 有些）
- [ ] 上反对、下反对各得出什么结论（至少一假 / 至少一真）
- [ ] 联言命题的矛盾；相容选言的矛盾
- [ ] 不相容选言"要么…要么"的真假要求

- [ ] 找结论的标志词（说出 6 个）
- [ ] 削弱三角度，各在什么情况下优先
- [ ] 加强三角度；前提型两法

- [ ] 和定最值怎么定方向；保证数怎么算
