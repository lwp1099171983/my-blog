## 一、全景树

```
言语理解与表达
├── 片段阅读（提问方式不同 → 5 大题型，讲义 p1-21）
│   ├── ① 主旨观点题    「主要介绍/概括最准确/意在说明」
│   │     三步法：主题词 → 层次 → 选项
│   ├── ② 标题添加题    「最适合做标题」        ≈ 主旨能力 + 标题三特点
│   ├── ③ 细节题        「理解(不)准确/与原文相符/没有提及」
│   ├── ④ 下文推断题    「接下来最可能讲述」     核心看尾句
│   └── ⑤ 词语理解题    「某词/句指的是」        指代词/特殊含义词
├── 逻辑填空（考点双维度：语境定方向 + 词语定选项，p22-34）
│   ├── 语境分析：上下文四大关系（反对/解释/递进/并列）→ 判定标志定关系
│   ├── 词语辨析：语素联想 + 语境联想；五角度（侧重/轻重/搭配/感情/句法）
│   └── 虚词辨析：关联词搭配 + 句间关系
├── 语句表达（p35-51）
│   ├── 句子排序：定首句 → 抓标志 → 理关系
│   ├── 句子填空：话题一致 + 句间关系一致（段首/段中承上启下/段尾总结）
│   └── 病句辨析：八大病型 + 两步检查（提主干 → 查关键词）
└── 文章阅读/综合分析（p52-58，一篇文章 5 题 ×2 篇材料）
      微观类 5 种（细节判断/细节查找/句子填空/词语理解/逻辑填空）
      宏观类 3 种（主旨观点/标题添加/语段归位）
      作答三步：看题定题型 → 读文做标记 → 先微观后宏观
```

## 二、串联主线（脑子里要有这 4 条线）

| 主线 | 贯穿点 | 记忆锚 |
|---|---|---|
| **主旨能力线** | 主旨观点题 → 标题添加题（能力相同）→ 文章阅读宏观题 | 一切宏观题=找重点+同义转述；重点看主题词和层次 |
| **句间关系线** | 片段层次分析（转折/承接/解释/并列）↔ 逻辑填空语境（反对/解释/递进/并列）↔ 排序标志词 ↔ 填空句间一致 | 关联词既是"分层信号"也是"填空信号"：但是=反对、因此=解释、甚至=递进、分号=并列 |
| **位置思维线** | 下文推断（尾句）↔ 排序（首句+尾句）↔ 填空（段首/中/尾作用不同）↔ 语段归位 | 位置决定功能：段首引话题、段中承上启下、段尾总结/提新话题 |
| **表述排查线** | 细节判断设错 5 类 ↔ 病句 8 型 ↔ 语段归位关键词定位 | "无中生有/偷换概念/绝对表述"既是细节题陷阱，也是病句病根 |

## 三、速记口诀

- **主旨三步**：先抓主题词（高频词/关键句陈述对象），再分层（转折重点在后、并列要概括、隐性主旨选对策），最后选项验（同义转述才选）。
- **细节五坑**：无中生有、正话反说、绝对表述、偷换概念、混淆范围。
- **下文推断**：尾句提话题→接着讲话题；尾句提问题→接着讲对策/分析；选项三排除：无关、已讲（本文信息）、跳跃。
- **语境四关系**：反对（虽然但是/并非而是）、解释（换言之/冒号/因此）、递进（甚至/更/何况）、并列（和/顿号/分号）。
- **词语五辨**：侧重、轻重、搭配、感情、句法。
- **排序三步**：看选项定首句（含指代词/转折因果开头的不做首句），抓五类标志（指代/关联/顺序/总结/重复词），归类理顺。
- **病句八型**：用词、搭配、语序、残缺、赘余、表意不明、结构混乱、不合逻辑；检查口诀"先提主干，再查关联"。

## 四、做题路由（拿到题 10 秒内）

```
看提问方式
 ├─ 主要介绍/意在说明/概括 → 主旨三步法
 ├─ 最适合做标题 → 按主旨做 + 选"精炼生动"项
 ├─ (不)准确/相符/没有提及 → 回文定位，查五坑
 ├─ 接下来讲什么 → 只看尾句 + 三排除
 ├─ "X"指的是 → 前文就近找，特殊含义贴主题
 ├─ 填横线选词 → 先看标志定关系，再五辨选词（虚词题查搭配）
 ├─ 排序 → 定首句排除，抓标志捆绑
 ├─ 填句子 → 话题一致 + 位置功能
 ├─ 找语病 → 提主干 → 对照八型
 └─ 文章阅读 → 先做微观后做宏观，边读边标记
```
