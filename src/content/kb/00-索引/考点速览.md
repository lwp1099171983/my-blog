## 极速路由：看到问法 → 定题型

| 问法长这样 | 就是这题 | 方法入口 |
|---|---|---|
| 主要介绍 / 意在说明 / 概括最准确 | **主旨观点题** | 主题词 → 层次 → 选项 |
| 最适合做标题 | **标题添加题** | 按主旨做 + 选精炼生动 |
| 理解（不）准确 / 与原文相符 / 没有提及 | **细节题** | 回文定位，查五坑 |
| 接下来最可能讲 | **下文推断题** | 只看尾句 + 三排除 |
| 文中"X"指的是 | **词语理解题** | 前文就近找 |
| 依次填入横线（实词/成语/关联词） | **逻辑填空** | 定关系 → 五辨选词 |
| 句子排序 / 填句子 | **语句表达** | 定首句 / 话题一致 |
| 没有语病的一项 | **病句辨析** | 提主干 → 对照八型 |
| 一篇文章带 5 小题 | **文章阅读** | 先微观后宏观 |
| 所有/有些/某个、真假话、如果…那么 | **命题推理（直言/复言）** | 背规则：矛盾→推出→翻译（假言） |
| 找突破口 / 元素匹配 | **朴素逻辑** | 突破口 → 代入排除/假设/图表 |
| 最能削弱 / 加强 / 补充前提 | **论证题** | 拆三要素 → 三角度 → 力度比较 |
| 图形找规律 / 折纸盒 / 拼接 | **图形推理** | 相似看位置叠加 · 相异看特性数量 · 立体折叠 · 拼接定方法 |
| 符合 / 不符合该定义 | **定义判断** | 抓八要点 → 排除法 |
| 两词/三词/括号找关系 | **类比推理** | 三大类词间关系，横向优于纵向 |
| 5 短句排序 | **事件排序** | 对比首尾句 → 对比选项差异 |

### 第02章 片段阅读（PDF 1-21）→ [章节文件](/kb/01-职测/01-言语理解/第02章-片段阅读)

> 五大题型由**提问方式**决定；主旨观点题是根基，标题/文章阅读宏观题都复用它。

| 考点 | 问法关键词（识别） | 核心方法（完整并列项） | 考频 |
|---|---|---|---|
| **主旨观点题** | 主要介绍 / 意在说明 / 概括最准确 | **三步法**：①**主题词**（高频词、关键句陈述对象 → 先排"偏题"项）；②**层次**（转折——重点多在转折后、承接、解释、并列——无主次需提炼共性或全面概括；**隐性主旨**三类：重要性+缺陷、问题+危害、问题+原因 → 选针对且可操作的**对策**）；③**选项**（先同义转述，再排除：侧重不同 / 偷换概念 / 概括不全 / 推断过度） | **高频** ★★★★★ |
| **标题添加题** | 最适合做这段文字标题 | 能力等同主旨观点题；标题三特点：**主旨明确、内容精炼、形式新颖**；选项两特点：紧扣主旨、形象生动 | 中频 ★★★ |
| **细节题** | 以下理解（不）准确 / 与原文相符 / 没有提及 | 细节判断·**设错五坑**：无中生有、正话反说、绝对表述、偷换概念、混淆范围；细节查找：定查找内容 → **定位原文** → 筛选项 | **高频** ★★★★ |
| **下文推断题** | 接下来最可能讲述 / 介绍 | **只看尾句**：尾句提出话题 → 延续话题；尾句提出问题 → 分析/解决。三排除：无关信息、本文信息（已论述）、跳跃信息 | 中频 ★★★ |
| **词语理解题** | 文中"X"指的是 / 含义是 | 两类：指代性词语（**前文就近**找）；特殊含义词语（**贴近主题** + 注意修辞） | 中频 ★★★ |

### 第03章 逻辑填空（PDF 22-34）→ [章节文件](/kb/01-职测/01-言语理解/第03章-逻辑填空)

> **双维度**：语境定方向（四大关系）→ 词语定选项（五辨角度）。

| 考点 | 问法关键词（识别） | 核心方法（完整并列项） | 考频 |
|---|---|---|---|
| **语境分析** | 依次填入横线最恰当（实词/成语） | 三步：定关系 → 找提示信息 → 筛选项。**四大关系·判定标志**：①**反对**（转折词：虽然…但是/然而/不过/却/实际上；对照词：多…/过去…如今/并非…而是/不同于；否定词：无法/不可能/没有/不会）②**解释**（同义互换：无异于/类似于/换言之/或者说/如/像；指代词；冒号/破折号；总结词；因果/假设/条件词；无标志看空前空后）③**递进**（甚至/而且/竟/更/上升到/以至/不仅…而且/何况——方向一致程度有别）④**并列**（和/又/另外/此外/既…又；或者/要么；顿号/分号；并列短语句） | **高频** ★★★★★ |
| **词语辨析** | 同上（近义实词/成语区分） | **两法**：语素联想法（拆语素释义/组词）、语境联想法（日常/官媒用法）。**五角度**：词义侧重、词义轻重、搭配对象、感情色彩、句法功能 | **高频** ★★★★★ |
| **虚词辨析** | 依次填入关联词 | 两核心：关联词搭配、句间关系 | 低频 ★★ |

### 第04章 语句表达（PDF 35-51）→ [章节文件](/kb/01-职测/01-言语理解/第04章-语句表达)

> 排序抓**首句+标志**，填空看**位置**，病句走**主干→关键词**两步。

| 考点 | 问法关键词（识别） | 核心方法（完整并列项） | 考频 |
|---|---|---|---|
| **句子排序** | 将以下句子重新排列 / 排序最合适 | **三步**：①定首句（**不做首句**：指代不明、转折/因果/总结词开头、具体描述句；**可做首句**：背景介绍、概念介绍、引用）；②**五类标志**：指代词（在所指对象后）、关联词（定逻辑顺序）、顺序词（时间从古至今/空间渐进）、总结词（置尾句）、重复词（捆绑：引出→解释→应用）；③句间关系定整体顺序 | **高频** ★★★★ |
| **句子填空** | 填入横线处最恰当 | **两原则**：话题一致（陈述对象与文段一致）；句间关系一致（**位置定作用**：段首引话题/总领、段中承上启下、段尾总结/结论） | **高频** ★★★★ |
| **病句辨析** | 没有语病 / 有语病的一项 | **八大类型**：①用词不当（不合习惯、逻辑错误）②搭配不当（主宾、主谓、谓宾、修饰语与中心语）③语序不当（定语、状语、定状错位、关联词与主语错位）④成分残缺（主/谓/宾）⑤成分赘余 ⑥表意不明（指代不明、歧义）⑦结构混乱（句式杂糅、中途易辙）⑧不合逻辑（并列不当、否定不当、主客颠倒、两面对一面、自相矛盾）。**检查两步**：主干枝叶梳理 + 关键词语检查（并列成分、关联词） | 中频 ★★★ |

### 第05章 文章阅读-综合分析（PDF 52-58）→ [章节文件](/kb/01-职测/01-言语理解/第05章-文章阅读-综合分析)

> 一篇文章 5 题；**先微观后宏观**，边读边标记。

|---|---|---|---|

| **宏观类（3 种）** | 主旨观点 / 标题添加 / 语段归位 | 主旨：段落主旨概括+全文观点把握；标题：复用标题添加法；语段归位：抓关键信息（主题词/关联词/指代词）→ 定位 → 析句间关系定位置 | 中频 ★★★ |
| **作答三步** | 整篇材料 | ①看题**定题型** ②读文**做标记**（关键词：关联词/指代词/总结词；关键句：首尾句/观点句/结论句；关键段：首尾段/承上启下段）③做题**先微观后宏观** | **高频** ★★★★ |

### 第02章 逻辑判断（PDF 1-40）→ [章节文件](/kb/01-职测/02-判断推理/第02章-逻辑判断)

> 必然性推理（直言/联言选言/假言/朴素逻辑）是可能性推理的基础，先背规则再做题。

| 考点 | 问法关键词（识别） | 核心方法（完整并列项） | 考频 |
|---|---|---|---|
| **直言命题** | 所有/有些/某个、真假话、据此推出 | 六类型（所有/有些/某个 × 是/非）；**矛盾**三对（所有A是B↔有些A非B、所有A非B↔有些A是B、某个A是B↔某个A非B）→ 矛盾法"一找二绕三回"；**推出**（知真求真：翻译题干→应用推出）：所有A是B→某个A是B→有些A是B（所有非同理）；**反对**：上反对（所有是↔所有非，至少一假）、下反对（有些是↔有些非，至少一真）→ 反对法"一找二绕三回"；**三段论**：四种标准形式、文氏图；前提型用排除法、结论型用画图法 | 低频 ★★★ |
| **联言、选言命题** | 且 / 或 / 要么…要么、真假话 | 联言 p且q：一假则假、全真则真，矛盾=非p或非q；相容选言 p或q：一真则真、全假则假，矛盾=非p且非q；不相容选言"要么p要么q"：有且只有一种情况为真（同真同假均为假）；联言/选言各有推理规则（由命题真假反推支命题真假） | 低频 ★★★ |
| **假言命题** | 如果…那么 / 只要…就 / 只有…才 | **翻译**：充分条件→必要条件；充分在前=前→后（如果…那么/只要…就），必要在前=后→前（只有…才）。**推理规则**：肯前必肯后、否后必否前，否前/肯后推不出必然结论（逆否等价）。**矛盾**=p且非q。真假话用矛盾法"一找二绕三回" | **高频** ★★★★★ |
| **朴素逻辑** | 找突破口 / 元素匹配 | **突破口思维**：确定条件（能得出确定信息）、关联条件（出现次数多的元素串联多条件）；**解题方法**：代入排除法（选项对应关系给得全）、假设法（真假话不确定）、图表法（列表法/画图法） | **高频** ★★★★★ |
| **论证基础** | 削弱/加强等论证题的分析前提 | 三要素：结论、论据、论证联系；找结论标志词（因此/所以/认为/相信/宣称/说明/表明/意味着/预测/推测/由此可知/据此推出/得出结论）；信息提取：剔除背景说明/概念介绍/以往认知，提炼对象及性质/原因/结果/影响/做法；五种论证过程（论据→结论；论据1+论据2→结论；论据→结论1、2；论据→中间结论→最终结论；只有结论） | **高频** ★★★★★ |
| **削弱型** | 最能削弱 / 不能削弱等变式 | 削弱三角度：①**削弱结论**（直接否定；只有结论型仅此路）②**削弱论证联系**（切断论据与结论的联系；论据与结论概念或对象不一致时优先）③**削弱论据**（论据为某人/机构观点、调查结果、实验发现时） | **高频** ★★★★★ |
| **加强型** | 最能加强 / 支持 / 补充前提 / 假设 | 一般加强三角度：①加强结论（解释结论/举例）②加强论证联系（**概念或话题不一致时优先**，建立联系）③加强论据；前提型：**搭桥法**（找论据与结论的不同概念→建立联系）、**反向验证法**（否定选项代入，结论不成立者为必需前提） | **高频** ★★★★★ |
| **力度比较** | 两选项都能削弱/加强 | **本质>现象、必然>可能、量大>量小、直接>间接、综合>单一** | **高频** ★★★★★ |
| **解释型/结论型/评价型** | 最能解释、由此（不能）推出、相同/相似/一致 | 解释：找现象→找原因；结论：选项代入定位；评价（相似结构）：分析题干推理形式/论证方式 → 选结构一致的选项 | 低频 ★★ |
| **综合判断推理** | 一则材料回答 1-2（或多）题 | 材料承载多道小题（分组/匹配推理 + 削弱/评价混合）；先通读材料梳理确定条件，再逐题套对应题型方法 | 低频 ★★★ |

### 第03章 图形推理（PDF 41-67）→ [章节文件](/kb/01-职测/02-判断推理/第03章-图形推理)

> 按图形特征定规律：相似（元素相同）→位置/叠加；相异→特性/数量/分布；立体→折叠/视图/拼接。

| 考点 | 图形特征（识别） | 核心方法 | 考频 |
|---|---|---|---|
| **图形相似·位置规律** | 图形相似且组成元素完全相同 | **平移**（方向：上下左右/顺逆时针；距离：等距离/依次递增）、**旋转**（方向+角度：30°/45°/60°/90°等）、**翻转**（左右翻转/上下翻转） | **高频** ★★★★★ |
| **图形相似·叠加规律** | 图形相似且元素同中有异 | **直接叠加**、**去同求异**、**去异求同**、**特殊运算**（常见：黑白运算） | **高频** ★★★★★ |
| **图形相异·图形特性** | 相似度低且自身特性明显 | **对称**（轴对称：对称轴数量/方向/与点线面关系；中心对称；轴对称+中心对称）、**直曲**（全直线/全曲线/有直有曲）、**开闭**（开放/封闭） | **高频** ★★★★★ |
| **图形相异·数量规律** | 相似度低且无明显特性 | 数**点**（交点数/特殊交点：十字、直曲、切点、内外部）、数**线**（直线/曲线数、笔画数）、数**面**（封闭区域/部分数）、数**元素**（种类数/个数）、数**角**（锐/直/钝角） | **高频** ★★★★★ |
| **图形相异·元素分布** | 多元素排列分布特征 | **元素遍历**、**相对位置** | 中频 ★★★ |
| **立体图形** | 折纸盒/拆纸盒、视图、截面、"俄罗斯方块" | **六面体**：图案在外侧；相对面不相邻（同行/列隔一个面、"Z"字形两端）；相邻面相对位置不变（看公共边）；**四面体**；**三视图**（投影还原）；**截面图**；**立体拼接**：凹凸一致、"个数"相等、分层讨论 | 中频 ★★★ |
| **平面拼接** | 拼合图形（只能平移） | **常规平面拼接**：特殊线条法、平行线条拼接法；**小方格型平面拼接**：最大面定位法 | 低频 ★★★ |

### 第05章 类比推理（PDF 77-86）→ [章节文件](/kb/01-职测/02-判断推理/第05章-类比推理)

| 考点 | 问法关键词（识别） | 核心方法 | 考频 |
|---|---|---|---|

### 第13章 常用解题方法 → [章节文件](/kb/01-职测/03-数量关系/第13章-常用解题方法)

| 考点 | 识别关键词/环境 | 核心方法 | 考频 |
|---|---|---|---|
| **数论基础** | 所求为整数；除、整除、每、平均、分组 | 整除判定：2/5看末一位；4/25看末两位；8/125看末三位；3/9看各位和；11看奇偶位和之差。奇偶、质合、约倍特性辅助筛选 | ★★★ |
| **方程法** | 相等、共、比、倍、之和、之差、之积；或路程/工程/利润等公式 | 🟢 四步：找等量关系 → 设未知数 → 列方程 → 解方程。设小不设大；不定方程结合代入排除、奇偶、整除、尾数，任意范围可用赋0法 | ★★★★★ |
| **比例法** | 题干直接或间接给出分数、百分数、倍数或比例 | 🟢 三能力：化简（“分母是自己的，分子是别人的”）→ 统一（找不变量、统一份数、同比变化）→ 计算 | ★★★ |
| **赋值法** | 数据均为比例/分数/倍数/百分数；或 `C=A×B` 且仅一个实际量已知 | 判断适用性 → 确定赋值对象与数值 → 按题干关系计算 | ★★★★ |
| **十字交叉法** | 平均数、比重、浓度、利润率等比例混合 | 🔴 先确认分子能相加、分母能相加；部分比例分母之比 = 交叉作差之比，作差取大减小 | ★★★ |

### 第14章 常考题型（九大题型） → [章节文件](/kb/01-职测/03-数量关系/第14章-常考题型)

| 题型 | 识别与核心内容 | 公式/方法入口 | 重要性 |
|---|---|---|---|
| **等差数列** | 相邻项差相等 | 🔴 `a_n=a_1+(n-1)d`；`a_n-a_m=(n-m)d`；奇数项和=中间项×项数，偶数项和=中间两项和×项数/2 | ★★★★ |
| **经济利润** | 成本、售价、利润、利润率、打折、销量、分段收费 | 🔴 `利润=售价-成本=成本×利润率`；`成本=售价÷(1+利润率)`；分段计费按各段分别计算 | ★★★★ |
| **工程** | 工作量、效率、时间；合作或交替 | 🔴 `W=P×T`；给定时间型总量赋最小公倍数，效率制约型按效率比赋值，效率相同型效率赋1；交替工程按周期处理余量 | ★★★★★ |
| **行程** | 路程、速度、时间；相遇、追及、环形、牛吃草 | 🔴 `S=V×T`；相遇路程和=速度和×时间；追及路程差=速度差×时间；牛吃草 `Y=(N-X)×T` | ★★★★ |
| **排列组合** | 求方法数、结果数；有无顺序及限制条件 | 分类相加、分步相乘；排列有顺序、组合无顺序；🟢 枚举、优限、捆绑、插空 | ★★★ |
| **古典概率** | 结果有限且等可能 | 🔴 `P(A)=事件A样本数÷总样本数`；独立事件分类相加、分步相乘，计数常结合排列组合 | ★★★★ |
| **几何** | 平面/立体图形，面积、周长、体积、相似或直角关系 | 三角形、菱形、梯形、圆、扇形；勾股与特殊直角三角形；正方体、长方体、圆柱、圆锥、球公式 | ★★★★ |
| **最值** | “最大/最小”“至少…才能保证” | 和定最值：目标最大则其他尽量小，目标最小则其他尽量大；保证数=最不利数+1 | ★★★ |
| **容斥** | 多个集合有重复计数；只属于、都属于、都不属于 | 二者 `I=A+B-A∩B+M`；三者标准公式/非标准公式；交集最小：二者 `A+B-I`，三者 `A+B+C-2I`；必要时画文氏图 | ★★★ |

## 资料分析

| 题型 | 识别与核心内容 | 公式/方法入口 | 重要性 |
|---|---|---|---|
| **一般增长** | 现期、基期、增长量、增长率；同比与环比 | 🔴 `增长量=现期值-基期值`；`增长率=增长量/基期值`；现期值、基期值、增长量、增长率四量互推 | ★★★★★ |
| **间隔增长** | 间隔期连续增长，求间隔增长率或间隔基期值 | 🔴 间隔增长率公式、间隔基期值公式 | ★★★ |

| **混合增长** | 总体由多个部分构成，求或比较整体增长 | 🟢 根据各部分的基期量、增长量或增长率选择混合增长方法 | ★★★ |

| **平均数** | “平均每”“人均”“单位”；现期、基期或变化 | 🔴 `平均数=总量/份数`；区分现期平均数、基期平均数和平均数变化 | ★★★★ |
| **倍数** | “是……的几倍”；现期或基期比较 | 🔴 `倍数=A/B`；基期倍数按对应基期量计算 | ★★★ |
| **尾数法** | 简单加减，且选项末一位或末几位不同 | 🟢 优先看末三位以内；不够减要借位，小数位不足补0 | ★★★ |

| **比较大小** | 多个数或增长量的排序、大小判断 | 🟢 观察比较法、同位比较法、增长量大小比较 | ★★★★ |
